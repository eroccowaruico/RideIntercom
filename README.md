# RideIntercom

## 開発を始める

| 開発環境 | このcheckoutで開くファイル | 実行 |
|---|---|---|
| Xcode | `RideIntercom.xcodeproj` | 共有scheme `RideIntercom`、My MacまたはiOS Simulator |
| VS Code | `RideIntercom.code-workspace` | `Tasks: Run Task` → `RideIntercom: …` |

[Xcode / VS Codeの開発環境](docs/spec/scripts/開発環境.md)に、ファイル自動同期、package編集、ビルド・テスト・デバッグ、表示されない場合の確認方法を記載する。

仕様の正本は [要求](docs/requirements/requirements.md) と `docs/spec`。再実行可能な検証入口は [自動検証](docs/spec/scripts/自動検証.md) を参照する。
