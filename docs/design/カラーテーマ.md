# RideCom カラーテーマ

## 指示と背景

2026-11-01の利用者指示により、一般向け画面（Standard）・詳細表示（Advanced）・Watch・Widgetに共通するカラーテーマを定める。本書は[デザインシステム](デザインシステム.md)の色の正本である。策定時の実装はシステム標準色（`.green` / `.orange` / `.red` / `.blue`）と未定義の`AccentColor`だけで構成され、製品としての色の一貫性がなかった。RideComはバイク（春・夏・秋）とスキー・スノーボード（冬）のライディング中の会話を主用途とし、アイコンの「道とシュプール」「音声波形」を引き継いで、季節を限定しない**白・青・緑系の透き通った外観**を目指す。

本書は全体の配色設計である。2026-11-02にiPhone・iPad・MacのAppの`AccentColor`と、Standardの通話・ユーザー・グループ画面の背景（`BackgroundTop`／`BackgroundBase`）を適用した。Watchには青のAccentColorと通常時のnavigation背景を適用し、利用不可時は黒を使う。状態色・音量メーター・Widgetの専用配色は未適用。現行のトークンと強制規約は[デザインシステム](デザインシステム.md)、画面ごとの配置は[画面構成とレイアウト](一般向け/画面構成とレイアウト.md)、見た目の確認は[デザイン見本](一般向け/デザイン見本.html)を参照する。アプリアイコンは現行の配色を維持する（[アプリアイコン配色の検討](アプリアイコン配色案.md)）。アイコンは確定前であり、確定時に本書の値との調和を再確認する。

## テーマの考え方

| 観点 | 方針 | 理由 |
|---|---|---|
| 主題 | 白、空の青、緑、声の青緑。雪・新緑・紅葉のような季節の情景は描かない | バイク（春・夏・秋）とスキー・スノーボード（冬）の両方で同じ印象になるよう、季節を問わない色だけを使う。アイコンの道とシュプール（青系）と音声波形（水色〜青緑）を引き継ぐ |
| 透明感 | 背景はごく淡い空色の縦グラデーションに白いカードを重ねる。カード・操作はシステムのMaterial／Liquid Glassを重ねる | 独自の半透明描画を作らず、OS標準のガラス表現で「透き通った」質感を得る |
| 色の量 | 画面の大部分は白／夜の紺と標準の文字色。ブランド色は主要操作・状態・声の可視化だけに使う | 状態色の意味を薄めず、屋外の強い日差しでも主要操作を見つけやすくする |
| 澄んだ明るさと視認性 | ライトは淡い空色の背景に白いカードを重ね、ブランド色は白いカードの上で文字4.5:1を満たす範囲で最も明るい青にする（[アクセシビリティの検証](#アクセシビリティの検証)）。状態文字は必ずSF Symbolsと併記する。「コントラストを上げる」設定では濃い値へ切り替え、文字4.5:1以上を満たす | 2026-11-01の利用者指摘で、濃い青・緑は澄んだ印象を損なうと判断した。直射日光やゴーグル越しで見づらい利用者には、OSのコントラスト設定で濃い値を提供する |
| 標準への寄せ方 | ブランド色はAsset Catalogの名前付きColor（Any / Dark / High Contrast）で定義し、SwiftUIの`Color("…")`・`tint`・`.accentColor`で参照する | ライト／ダーク・コントラストを上げる設定・Widgetのレンダリングモードへ自動で追従させる |

### アクセシビリティの検証

2026-11-02、画面へ反映した値（AccentColor ライト`#1584CC`、BackgroundTop `#F2F9FE`／ダーク`#0F2238`、BackgroundBase `#FFFFFF`／ダーク`#08111D`）を検証した。「背景が見にくい」原因は次のとおりで、上表の値へ改める。

| 問題 | 反映済みの値での比 | 原因 | 対応 |
|---|---|---|---|
| ライトで白いカード・Formの行が背景に溶ける | 下端1.00、上端1.06 | 背景の下端が純白で、白いセルと同じ色 | 背景をApple標準のgrouped背景と同程度の淡い空色（`#E6F1FA`→`#ECF2F8`）にし、白いカードとの差を1.12以上にする |
| ダークでセルが背景に溶ける | 上端1.06 | 背景上端の紺`#0F2238`がセル`#1C1C1E`と同じ明るさ | 背景をセルより暗い紺（`#050E1A`→`#03070D`）にする |
| ライトの青い文字が読みにくい | 背景上3.80、白の上4.04 | 文字の基準4.5未満 | `#1179C0`にし、白いカードの上で4.65、白文字の塗りで4.65にする |
| 状態の記号が薄い | 緑・オレンジ約2.1 | 図形の基準3未満 | 記号だけで状態を伝えない（文字を必ず併記）。「コントラストを上げる」では濃い値を使う |
| 補助の文字（`secondaryLabel`） | 約3.3 | OS標準の値。淡い背景でわずかに下がる | footer・補足に限り、状態や操作の理由など読めないと困る情報を補助の文字だけに置かない |

点検の手順:

| 対象 | 確認すること |
|---|---|
| 色の組合せ | 上表の比を下回らないこと。文字は4.5、17pt以上の太字と図形は3以上 |
| 外観の設定 | ライト／ダーク、コントラストを上げる、透明度を下げる、カラーフィルタ（色覚の種類ごと）で、状態が文字と記号で区別できること |
| 文字サイズ | Dynamic Typeの最小〜アクセシビリティ最大（AX5）で、切れ・重なり・語の途中の折り返しがないこと |
| 読み上げ | VoiceOverで、状態・操作名・値が読めること。ミュートなど状態のある操作は値を読むこと |
| 屋外 | 直射日光・ゴーグル越しの実機確認は[未確認事項](../validation/未確認事項.md#画面デザインの実環境受入)で受け入れる |

## 状態色への割当て

[デザインシステム](デザインシステム.md#カラートークン)の状態トークンの意味は変えず、値だけをテーマへ揃える。

| 状態トークン | 現行値 | テーマ適用後 | 方針 |
|---|---|---|---|
| success | `green` | `RideGreen` | 会話中・接続成功。ブランドの緑と同一にする。2026-11-01の利用者指摘で濃い緑をやめ、明るい若葉寄りの緑にした。状態の文字は`textPrimary`のままにし、記号だけを緑にする |
| info | `blue` | `AccentColor` | 情報提示・受信中。rideBlueと同一にする |
| warning | `orange` | `Warning`（ライト`#FFAC33`／ダーク`#FFB340`／コントラストを上げる`#A35400`） | 接続待ち・音声停止・注意。2026-11-01の利用者指摘でシステムの強いオレンジから明るい琥珀色へ変更。白に対し1.87のため記号・点・ProgressViewにだけ使い、文字は`textPrimary` |
| danger | `red` | `Danger`（ライト`#F5484E`／ダーク`#FF6B6B`／コントラストを上げる`#C4161C`） | ミュート・切断・失敗・削除。システムの赤より少し明るく冷たい赤。白い記号・文字を載せた塗りはシステムの赤と同じ3.55を保つ。ボタンの塗り・記号・destructiveボタンの文字に使い、エラー本文は`textPrimary`＋赤の記号にする |
| neutral | `secondary` | `secondary` | 未接続・非稼働 |
| 声の可視化（新規） | `success` / `info`の流用 | `VoiceAqua` | メーター・話者表示を接続状態の緑から分離し、「つながっている」と「声が出ている」を区別する |

声の可視化はデザインシステムに新規トークン`voiceLevel`として追加する。追加は実装と同じ変更で行い、未使用トークンを先に置かない。

## 面と背景

| 面 | ライト | ダーク | 実装の指定 |
|---|---|---|---|
| 主要導線画面の背景 | backgroundTop→backgroundBaseの縦グラデーション | 同じトークンのダーク値 | `List`／`ScrollView`の`.scrollContentBackground(.hidden)`と`.background(LinearGradient(...))`。現行`callScreenBackground`の値を置き換える |
| カード・グループ化した行 | システムMaterial | システムMaterial | `List`の`insetGrouped`行、または`.glassEffect(.regular, in: .rect(cornerRadius:))`。カード独自の不透明色を作らない |
| 主要操作 | rideBlueのガラス塗り | rideBlueのガラス塗り | `.buttonStyle(.glassProminent)`と`.tint(.accentColor)`。切断とミュート中の選択状態だけ`.tint(Color("Danger"))` |
| 補助操作 | 透明ガラス | 透明ガラス | `.buttonStyle(.glass)` |
| 設定画面 | grouped Formの標準背景 | 同左 | 背景グラデーションを適用しない。設定は標準Formの見た目を保つ |
| 詳細表示（Advanced） | 主要導線画面と同じグラデーションと白いカード | 同左 | 一般向けと同じテーマを使う（[StandardとAdvancedの違い](デザインシステム.md#standardとadvancedの違い)）。診断のカードも白いカードの上に段の行を並べる |

Liquid Glassの適用は必須条件とする（[操作と状態の共通規則](デザインシステム.md#操作と状態の共通規則)）。テーマの透明感はLiquid Glassを前提に成立させ、ガラスを使わない不透明な面へ置き換えない。ガラス・Materialの不透明度や光沢はOSに任せ、独自のblur・半透明色・影を描かない。「透明度を下げる」設定ではOSがガラスを不透明化するため、カードと背景の区別は面の差に加え、標準の行区切り・余白でも成立させる。

## Watchの配色

watchOSは常に暗い外観で表示する。背景は黒を基本に、RideComの画面であることをrideBlueのコンテナ背景で示す。黒の上に緑を重ねると濃い緑に見えるため、Watchの背景に緑は使わない。通話の状態は文字とSF Symbolsで示す。

| 状態 | コンテナ背景 | 主要操作 | 実装の指定 |
|---|---|---|---|
| 接続先一覧（待機） | rideBlueのグラデーション | 行のtintはrideBlue | `.containerBackground(Color.accentColor.gradient, for: .navigation)` |
| 接続待ち | rideBlueのグラデーション | 切断だけ表示 | 状態文は文字と`ProgressView`で示し、背景色で接続待ちを表さない |
| 通話中・送話待機 | rideBlueのグラデーション | 送話パネルはrideBlueの淡いガラス | 背景は「通話が成立している」ことだけを示す。マイクオフの表示はしない |
| 通話中・送話中 | rideBlueのグラデーション | 送話パネルをvoiceで塗る | パネルの色に加え、文言「話しています」とSF Symbolsの波形で示す |
| 切断 | — | 左上のボタンだけdanger | 誤操作を避けるため上部に置き、確認を出す |
| 接続待ちの進行表示 | — | `ProgressView`だけwarning | 文字は白のまま |
| iPhone未接続・失敗 | 背景色なし（黒） | 再試行だけ | 文言と`iphone.slash`等で理由を示す |

## 実装時の変更点

| 対象 | 変更内容 |
|---|---|
| `RideIntercom/Assets.xcassets` | `AccentColor`・`BackgroundTop`・`BackgroundBase`を[アクセシビリティの検証](#アクセシビリティの検証)の値へ改める（2026-11-02時点で反映済みの値は旧い値）。ライト・ダーク・コントラストを上げる値を設定。`RideGreen`・`VoiceAqua`・`Warning`・`Danger`・`BackgroundTop`・`BackgroundBase`・`DeepNavy`を追加 |
| `RideIntercomWatch/Assets.xcassets` | `AccentColor`と`RideGreen`・`VoiceAqua`・`Warning`・`Danger`を同値で追加 |
| Widget extension | 同じColorとカスタムシンボル`ridecom.glyph`をWidget targetのAsset Catalogへ置く。AppとWidgetで値を二重管理しないよう、共有の配置方法は実装時にtarget所属で決める |
| `AppTheme.swift` | `AppColorPalette.success` / `info` / `warning` / `danger` / `callScreenBackground`の値をテーマへ置換し、`voiceLevel`を追加。トークン名は変えない |
| 状態の文字 | success・warning・dangerの色を文字から外し、記号・点・塗りへ移す。[デザインシステム](デザインシステム.md#テキスト色規約)の「エラー本文はdanger」「主状態値は状態色」の規約を、実装と同じ変更で「文字は`textPrimary`、状態色は隣の記号」へ改める |
| [デザインシステム](デザインシステム.md) | カラートークン表の値・`voiceLevel`を実装と同じ変更で更新 |

画面側に16進値・`Color(red:green:blue:)`を直接書かない。すべてAsset名または`AppColorPalette`経由で参照する。

## 未決事項

| 事項 | 判断の材料 |
|---|---|
| アイコン確定後の値の微調整 | アイコンの最終色とrideBlue・voiceの色相を照合する。コントラスト比の基準は維持する |
