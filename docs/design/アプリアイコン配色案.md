# RideCom アプリアイコン配色の検討

## 指示と結論

2026-11-01の利用者指示により、[カラーテーマ](カラーテーマ.md)に合わせたアプリアイコンの配色案を作成し、HTML見本で比較した。対象はホーム画面・Watch・設定に表示されるアプリアイコンであり、アプリ内のSF Symbolsは[アプリ内アイコン定義](アイコン定義.md)で扱う。

結論として、どの案も現行の配色を超えなかったため**現行の配色を維持する**。HTML見本は不要として削除した。現行の図案・Liquid Glassの組み込みは[アイコン適用](../spec/App/UI/アイコン適用.md#正式アプリアイコン)と[開発環境](../development/開発環境.md#配布用アプリアイコン)を正本とし、変更しない。アイコンは引き続き確定前であり、現行の配色は季節を限定しない色の境目を狙ったものである。

## 今後の検討で守る制約

| 制約 | 内容 |
|---|---|
| 図形を変えない | `Road.svg`（道とシュプール）と`Waveform.svg`（音声波形）は二重の意味を持つ。図形の追加・置換で意味を上書きしない |
| 道とシュプール | 頭文字R × スキーのシュプール × 道。冬はシュプール、春・夏・秋は道として読める。色で雪面や路面のどちらかに寄せない |
| 音声波形 | 声 × 山並み・景色。雪の白・新緑・紅葉など季節を決める色を付けない |
| 季節 | RideComはバイク（春・夏・秋）とスキー・スノーボード（冬）の両方を対象にする。季節の情景を色で表そうとすると片方に偏り、配色が破綻する |
| Liquid Glass | `.icon`のLiquid Glassレイヤーを使い、光沢・影を図案へ焼き込まない（[デザインシステム](デザインシステム.md#カラーテーマと画面構成の設計案)） |

## 検討して採用しなかった案

| 案 | 内容 | 判断 |
|---|---|---|
| 山を加える | 背景に緑の山を置き、道を白で描く | 図形の二重の意味を壊すとの指摘で取り下げ |
| 雪をかぶった峰 | 波形の高い棒の先を雪の白、裾野を緑にする | 冬に偏るため取り下げ |
| 空 | 白→淡い空色の背景、青い道、青緑の単色波形 | 現行を超えないため不採用 |
| 澄んだ青 | 空の青の背景、白い道、淡い青緑の波形 | 現行を超えないため不採用 |
| 現行寄りの調整 | 現行の紺・青・水色を少しテーマ色へ寄せる | 現行を超えないため不採用 |

アプリの識別用にアイコン図形から作るカスタムシンボル`ridecom.glyph`は、配色の検討とは別に[アイコン定義](アイコン定義.md#カスタムシンボル)で扱う。
