# RideCom 画面構成とレイアウト

## 指示と背景

2026-11-01の利用者指示により、一般向け画面（Standard）・Watch・Widgetの画面構成とレイアウトを設計する。Apple HIGと標準のSwiftUI部品だけで組む方針は維持し、そのうえで最低限の配色・情報の優先度・状態ごとの見え方を整える。[一般向け招待と利用制限の見直し](../../backlog/一般向け招待と利用制限・料金の見直し.md#画面仕様と残る改善)に関連するデザインの設計案にあたる。

本書は実装前の設計案。現行の項目・識別子・発現条件は[Call画面](../../spec/App/UI/Call.md)、[Settings画面](../../spec/App/UI/Settings.md)、[Watch操作](../../spec/App/Watch操作.md)、[システム表示と通話操作](../../spec/App/システム表示と通話操作.md)を正本とし、実装と同じ変更でそれらを更新する。配色は[カラーテーマ](../カラーテーマ.md)、見た目は[デザイン見本](デザイン見本.html)を参照する。Advancedの診断画面は対象外とし、テーマのtintだけが反映される。

## 現行UIの調査結果

| 対象 | 現在の構成 | 問題 |
|---|---|---|
| 色 | `AppColorPalette`がシステム色のみ。`AccentColor`は値なし。Call背景は`secondary.opacity(0.08)` | 製品の色がなく、標準の青と灰色だけ。状態色と声のメーターが同じ緑・青を共有する |
| Standard Call | 1つの`List`に直近通話・現在通話・保存エラー・宛先名（title2）・状態文・接続・招待・音声Section・通知・メンバーを順に積む | 主操作（接続／終了）が文字だけのボタンで、状態・宛先名と視覚的にまとまらない。マイクとスピーカーのミュートがToggleで、通話中の最重要操作に見えない。状態がテキスト1行で、色・アイコンがない |
| Standard Users / Groups | `Label`のボタン行。編集は行末の鉛筆ボタン | 行の情報が名前だけ。現在通話中の相手・グループが一覧で分からない。招待の入口がない |
| Settings | 単一Formに多数のSection | 一般向けの見出しの粒度は概ね妥当。並び順が利用頻度と一致しない |
| サインイン | 標準ScrollViewに説明とSign in with Apple | ブランドの第一印象がない |
| Watch | 1つの`List`に状態・Picker・押して話すボタン・終了・更新・呼出し・通話先一覧・注意書きを縦積み | 通話中に押して話すボタンが小さく、モードPickerや一覧と同じ画面に混在する。通話先一覧が下部に埋もれる。状態に色・アイコンがない |
| 選択通話Widget | `systemSmall`のみ。`RideCom`見出し・名前・`.bordered`ボタンを縦積み。背景`.fill.tertiary` | 状態が小さな文字だけ。通話中の操作がアイコンのみで意味が弱い。ブランド色がなく、色付き・クリア表示での見え方が考慮されていない |
| Live Activity | `phone.fill`と状態文・マイク状態・終了ボタン | 配色の指定なし。Dynamic Islandに声・ミュートの区別が弱い |

## Standardの方針

[絶対ルール](../../policies/開発方針.md#standardとadvancedの設計の絶対ルール): すべてのケースで、機械的な仕組みではなく利用者の意図から自然に分かるようにUXを先に定義し、全体の整合をとった上でUIをデザインする。一般の利用者が迷わずすぐに使え、不要な情報を目にしないことを満たす。画面の内容は[UXの定義](#uxの定義)から決める。

余白・寄せ・クリップ・サイズ・色・アイコン・コントロール・UI Stack・レイアウト・利用環境の前提は[デザインシステム](../デザインシステム.md)に従い、本書では繰り返さない。共通の規則は[操作と状態の共通規則](../デザインシステム.md#操作と状態の共通規則)、部品は[共通コンポーネント](../デザインシステム.md#共通コンポーネント設計案)のStandardの部品、Advancedとの違いは[StandardとAdvancedの違い](../デザインシステム.md#standardとadvancedの違い)を参照する。本書はStandard固有の判断だけを定める。

| 方針 | 内容 |
|---|---|
| 接続先が主役 | 通話画面の先頭は[状態ヒーロー](../デザインシステム.md#共通コンポーネント設計案)。接続先の名前を最も大きく、種別・人数は補助 |
| 見せないものを見せない | 経路・codec・ID・数値・内部の状態を出さない（[全体の整合](#全体の整合)）。それらはAdvancedが実装と対で示す |
| 共有は招待の一部 | 共有だけを独立した操作として置かず、新しい人を招待するときの送り先の選択としてだけ出す（[招待と共有](#招待と共有)）。例外は置かない |
| 説明を減らす | 画面の説明文・キャッチコピーを置かない。必要な案内は理由と次の操作の1文だけ（[日本語の最適化](#日本語の最適化)）。例外は取り消せない操作（アカウントの削除、保存データのリセット、サインアウト）の確認で、消えるもの・残るものを省略せずに書く（現行の[アカウント削除](../../spec/App/UI/Settings.md#アカウント削除)の文を維持） |
| 行の操作はスワイプとボタン | 行の削除・外す・取り消す・設定は、行のスワイプと、行から開く画面の中のボタンの2つで出す（グループの削除・抜けるはグループの設定の中だけ）。長押しのメニューは置かず、見つけにくい操作の案内の文も置かない（[リスト行とカード](../デザインシステム.md#リスト行とカード)） |

## UXの定義

[絶対ルール](../../policies/開発方針.md#standardとadvancedの設計の絶対ルール)により、Standardの画面はすべてこの節から決める。画面・部品・語は、下の表の「見えるもの」「すること」を満たすように後の節で定める。表にない画面・表示・操作をStandardに置かない。

### 意図と場面

| 場面 | 利用者の意図 | 見えるもの | すること | アプリが引き受けること | 見せないもの |
|---|---|---|---|---|---|
| 初めて開く | 使い始めたい | アプリアイコン・RideCom・サインインが必要な理由1文・Appleでサインイン | サインインを1回押す | 認証、端末の登録、インターネット接続の準備（自動化後） | アプリの説明、アカウントや端末の仕組み |
| 名前を決める | 仲間に分かる名前で呼ばれたい | 「あなたの名前」、例のプレースホルダー、はじめる | 名前を入れて「はじめる」 | 名前を仲間へ届ける | 既定の名前、本人確認の仕組み |
| この人と話したい | ハルカと話したい | ユーザーの一覧のハルカ | 行をタップ | 2人の場所への接続、ハルカへ呼び出しの通知を1回（[通知は親切な知らせ](../通知の設計.md#通知は親切な知らせ2026-11-10の利用者判断)）、経路の選択 | 内部の1対1のグループ、経路、ID |
| 相手がまだ来ない | ハルカが来るまで待つ | 状態ヒーローの「接続中」と「相手の参加を待っています」だけ | 何もしない（やめるときは「切断」） | 相手のいない場所への接続の維持、自動切断（[相手のいない場所で待つ](../操作の流れ.md#相手のいない場所で待つ)） | 通知を送れたか・届いたか・見たか、待った時間、期限 |
| このグループで話したい | 週末ツーリングのみんなと話したい | グループ（またはユーザーの一覧の「前回」）の行 | 行をタップ | 接続、経路の選択と切替。メンバーには通知しない | 経路、鍵、参加者の内部の状態 |
| 走行中に話す | 手を使わず話し続けたい | 何も見なくてよい（必要なら状態ヒーローの「会話中」） | 何もしない | 発話検出の送信、経路の自動復旧、自動切断 | 送信の仕組み、品質の数値 |
| 会話に来てほしい | ケンタにも今来てほしい | メンバーの行の「呼び出す」 | 押す | 選んだ人にだけ呼び出しの通知を1回。結果は追わない | 通知の許可の仕組み。送れない人には「呼び出す」を出さないだけ |
| 仲間に入れたい | 新しい人やマキを仲間にしたい | ユーザーの`+`「新しい相手を招待」、グループの「メンバーを招待」 | 選ぶ・名前を入れる・「招待を送る」。新しい人がいるときだけ送り先を選ぶ | 登録済みの人へは自動で届け、新しい人へはリンク。結果を「招待中」から参加へ進める | 届け方の違い、鍵、招待の形式 |
| 招待がつながらない | 相手とまだつながらない | 招待中の行の状態の語、招待の詳細の1文 | 「もう一度送る」 | 送った招待の再共有か、受け取った招待の返信の届け直しかを選ぶ | 再送・返信・同期の区別 |
| 招待を受け取った | 招待してくれた人とつながりたい | 招待の内容と「招待を受け入れる」 | 受け入れる | 登録、グループの保存、相手への返信 | 署名・期限の検証の仕組み |
| 呼び出された | 呼んでくれた人と話したい／今は無理 | 通知の「接続」 | 入るなら1回、入らないなら何もしない | 接続。会話中なら鳴らさず静かに届く | 通知の種類や許可の仕組み |
| 別の相手と話したい | 今の会話をやめてケンタと話したい | 通話表示・通話のシートの「切断」、ユーザーの一覧のケンタ | 切断してからケンタをタップ | 切断と接続。切断せずにタップしたときは今の通話のシートを開くだけ | 切替の確認 |
| 会話を終える | もう話さない | 「切断」 | 押して確認 | 切断、一覧へ戻す | 未接続だけの画面 |
| 自分の声・相手の声を止めたい | 一時的に話したくない／聞きたくない | 「ミュート」「消音」、音量 | 押す・動かす | 入力・出力を止める | 数値、出力先の仕組み |
| 声が聞こえない・届いていない | 自分の声が出ていないのか、相手の声が届いていないのか、鳴っていないのかを知りたい | 自分の行（マイクの入力）、相手ごとの行（届いている声）、音量の右端（実際の出力）の声のインジケーター | 見比べて、動いていない所を見つける（ミュート・消音を解く、音声機器を確かめる、音量を上げる） | 入力・受信・出力の大小の測定 | 数値、dBFS、段の名前、経路 |
| 音が出なくなった | また話したい | 状態「音声停止中」と理由1文、「音声を再開」 | 確認して1回押す | 接続は保ったまま、音声だけ再開 | 音声機器の内部の状態 |
| つながらない・使えない | なぜ話せないか知りたい | 理由1文と次の操作1つ（例: 利用権へ） | 次の操作を押す | 再試行、復旧 | エラーの内部の詳細、コード |
| 名前を変えたい | この人を自分の呼び方で呼びたい／グループ名を変えたい | 相手の設定・グループの設定の名前の欄 | 書き換えて「完了」 | 自分の端末だけに保存（呼び名）、全員へ届ける（グループ名） | 名前の保存の仕組み |
| やめたい | この人とのつながり・このグループをやめたい | 「ユーザーを削除」「グループから抜ける」（オーナー以外）「グループを削除」（オーナー）「外す」（利用権を持つ人） | 選んで確認 | 相手側へ反映、接続中なら切断（確認の文で先に伝える） | 同期の待ち、期限 |
| 相手にやめられた | — | 一覧から消える。開いていた画面は「削除されました」 | 何もしない（閉じる） | 古い操作の無効化 | 通知、同期の仕組み |
| 調整したい | 自動切断・感度・音を確かめたい | 設定の主画面の項目 | 選ぶ・押す | 保存と反映 | 専門の音声・通信の設定（Advancedだけ） |
| グループを使わない | 1対1だけで使いたい | ユーザーと設定のタブだけ | 何もしない | グループタブを既定で隠す。グループが届いたら1回だけ表示を聞く | グループの仕組み |
| 携帯を出さずに使いたい | 止まったときに手早く | Apple Watch・Widget・Control・ロック画面の状態 | 1回押す | iPhoneの通話を操作 | 経路・数値・取り消せない操作（ロック画面） |

### 全体の整合

| 整合させること | 決め方 |
|---|---|
| 同じ意図には同じ入口・同じ語 | [操作の語の意味](../デザインシステム.md#操作の語の意味)の表を正とし、画面ごとに言い換えない |
| 同じ結果には同じ状態の語 | 接続: 接続中→会話中。呼び出し: 通知を1回送るだけで、呼び出しの状態の語は置かない（[通知は親切な知らせ](../通知の設計.md#通知は親切な知らせ2026-11-10の利用者判断)）。招待: 招待中（受け取り待ち・届けています）→参加 |
| 見せないものを見せない | 経路（近距離・インターネット）、ID、数値（音量の%、人数以外の数）、内部の状態、仕組みの説明を、Standardのどの画面・システム表示にも出さない。設定の「通信経路」は利用者が選ぶ項目としてだけ置き、通話の画面には出さない |
| かなわないときの道 | 理由1文と、意図をかなえる操作1つ |

## iPhone・iPad・Mac（Standard）

### タブ構成

2026-11-02の利用者指示により、通話をタブから外し、人の一覧を最初の画面にする。操作の流れは[操作の流れ](../操作の流れ.md)に従う。記号は[タブとシステム表示の記号](../アイコン定義.md#タブ)、サイドバーへの切替は[レイアウトと画面サイズ](../デザインシステム.md#レイアウトと画面サイズ)に従う。

| 順 | タブ | 表示名 | 役割 |
|---|---|---|---|
| 1 | Users | ユーザー | 最初の画面。1対1の相手を選ぶとすぐ接続する。先頭に「前回」の接続先。招待の入口 |
| 2 | Groups | グループ | 通常グループを選ぶとすぐ接続する。作成の入口。既定では表示しない（[グループタブの表示](#グループタブの表示)） |
| 3 | Settings | 設定 | 利用前の調整 |

通話は、選んだときに開く画面（iPhoneは`sheet`、iPad・Macは`inspector`の右の列）と、閉じている間にタブバーの上に出る[通話のアクセサリ](../デザインシステム.md#共通コンポーネント設計案)で扱う。配置は[幅と高さによる配置](../デザインシステム.md#幅と高さによる配置)に従う。この構成は実装済み（[Call画面](../../spec/App/UI/Call.md#standardの通話ユーザーグループ)）。

#### グループタブの表示

[バックログ](../../backlog/未実装課題.md#個人招待の修復と画面アーキテクチャの整理)の「Standardのグループタブ表示設定」により、Standardのグループタブは既定で表示しない。1対1の接続はこの設定に関係なく使える。Advancedは常にGroupsを表示する。

| 項目 | 内容 |
|---|---|
| 設定の場所 | 「開発者向けの高度な設定」の「画面表示」Section。`Toggle`「グループタブを表示」（既定OFF）。footer「オンにすると、3人以上で話すグループの作成と一覧を使えます。1対1の接続はオフのままでも使えます。」 |
| OFFのとき | タブはユーザーと設定の2つ（iPad・Macのサイドバーも2項目）。すでに持っているグループには、ユーザーの一覧の先頭の「前回」（前回の接続先がグループの場合）、グループの呼び出しの通知、招待のリンクから接続できる。通話のシートのツールバーの「グループの設定」も使える |
| グループが届いたとき（OFFの場合） | [グループへの招待](../招待と登録の設計.md#グループへの招待)でグループを受け取ったら、次に一覧を表示したときに標準のアラートで1回だけ確認する。タイトル「グループタブを表示しますか？」、本文「{グループ}に招待されました。グループタブから接続できます。」、ボタン「表示する」「今はしない」。「今はしない」の後は、別のグループが届くまで聞かない |
| 切り替えたとき | ONで2番目にグループタブが入る。OFFにしたときグループタブを表示中ならユーザーへ戻す。通話・グループ・保存データは変えない。保存し、再起動後も同じ表示にする |

一般の利用者に内部の仕組み（1対1も内部ではグループであること）を見せない。1対1のための内部のグループは、設定に関係なくStandardのどの一覧にも出さない。

### 通話のシートの状態別構成

操作の流れ（選んですぐ接続、接続中は切らないと他に入れない、その場で追加、通知からの接続）は[操作の流れ](../操作の流れ.md)に従う。一覧で選ぶと通話のシートが接続中から開く。切断するとシートは閉じて一覧へ戻るため、未選択・未接続だけの画面は置かない。

画面は上から「状態把握（ヒーロー）> 主要操作 > 対象一覧 > 補助情報」の順に積む。背景はテーマのグラデーション、コンテナは`List(.insetGrouped)`で、ヒーローは`listRowBackground(.clear)`の行として置く。

| 状態 | ヒーロー | 主要操作 | 一覧・補助 |
|---|---|---|---|
| 接続待ち（Loading） | 状態「接続中」（`ProgressView`だけwarning）と補足「相手の参加を待っています」。相手のいない場所に入って待つ正常な状態で、時間が経っても、通知を送れなくても、近距離だけでも同じ表示のまま変えない（[相手のいない場所で待つ](../操作の流れ.md#相手のいない場所で待つ)） | 会話中と同じ円形3ボタン（ミュート・消音・切断）。塗りの主操作は置かない。やめるときも「切断」（「キャンセル」と言い換えない） | メンバー一覧。接続済みの人から状態が変わる |
| 会話中（Ideal） | 状態「会話中」（文字は標準色、`waveform`の記号だけrideGreen）。グループで一部の人だけが接続しているときは補足「{n}人が会話中」。経路は出さない。声のインジケーターは自分・相手ごと・出力の3か所（[会話中の配置](#会話中の配置)） | 円形3ボタン: ミュート（glass、記号は常に`mic.slash`。ミュート中はdangerで塗った選択状態と「ミュート中」）、消音（glass、記号は常に`speaker.slash`。消音中はaccentで塗った選択状態と「消音中」）、切断（danger prominent） | スピーカー音量Slider、メンバー一覧（話している人にvoiceのメーター。グループの未接続のメンバーで呼び出しの通知が届く人の行末に「呼び出す」。押すと1回送り、行の表示は変えない。[グループの呼び出し](../通知の設計.md#送り方)）、招待中の人（タップで招待の詳細） |
| 音声停止（Partial） | 状態「音声停止中」（`headphones`の記号だけwarning）と補足「音声機器を確認してください。接続は続いています。」 | ヒーローの直下に「音声を再開」（prominent）。その下の円形3ボタンは消音・ミュートを無効表示、切断は使える | 別の警告の面を足さない。メンバー一覧は維持 |
| エラー（Error） | 状態「音声エラー」（`exclamationmark.triangle.fill`の記号だけdanger） | 再試行がある場合だけその操作 | エラー本文（`textPrimary`）はヒーロー直下に1か所だけ |
| Apple Watchで操作中 | 状態は通常どおり | ミュートボタンの代わりに「マイクはApple Watchで操作」（`applewatch`、操作不可の表示） | 消音・切断は通常どおり |

### 招待と共有

[操作の語の意味](../デザインシステム.md#操作の語の意味)に従い、仲間を入れる意図は「招待」の1つにする。相手が登録済みか新しい人かで入口と語を変えず、届け方の違いはアプリが引き受ける。

| 場面 | 操作の流れ | 表示 |
|---|---|---|
| グループにメンバーを招待 | 通話画面またはグループの設定の「メンバーを招待」→ 自分のユーザー（見出し「あなたのユーザー」）から選ぶ、まだ登録していない人は同じ一覧の「新しい人を招待」で名前を入れる →「招待を送る」。選ぶ一覧の下に「自分を含めて{n}/8人」。新しい人がいるときだけ続けて`ShareLink`の共有画面 | 登録済みの人も新しい人も、メンバー一覧に「招待中」で入る（[グループへの招待](../招待と登録の設計.md#グループへの招待)）。招待だけでは呼び出さない |
| 新しい相手（1対1）を招待 | ユーザータブの`+` → 相手の名前を入れる（決められなければ空のまま。薄く見えている仮名の候補「青いキツネ」等になる）→「招待を送る」→ 直接招待の共有画面 | ユーザータブの「招待中」Sectionへ入る（[個人の招待](../招待と登録の設計.md#個人の招待)） |
| 招待が届かなかった・期限切れ | 「招待中」の行をタップして招待の詳細を開き、「もう一度送る」または「新しい招待を送る」 | 招待中の行は状態の語1つだけを出し、操作は詳細に置く。参加済みの人・通話画面の上部には置かない |
| 受け取った招待の返信が届いていない | 「招待中」の行（「返信が届いていません」）をタップし、「もう一度送る」 | 送った招待と同じ語にし、ボタンの下の1文（「{本人の名前}に、招待を受け入れたことをもう一度届けます。」）で何を届けるかを示す |
| 招待の取消 | 招待の詳細の最後のボタン、または「招待中」の行のスワイプ | 確認付きの破壊操作 |

共有画面を閉じた・共有が完了しただけでは参加とみなさない（[招待の見直し](../../backlog/一般向け招待と利用制限・料金の見直し.md#一般向け画面の招待と復旧)）。相手が招待から参加し、本人を識別できた時点でメンバー・ユーザーとして確定する。

グループのリンクは現行どおり宛先を持たず、開いた人が使える（[通信仕様](../../spec/App/通信仕様.md)）。宛先を持つのは個人の招待だけにする。

#### 音声チェック

マイクに声が入るか、実際に鳴るかを、通話の前に自分だけで確かめる。通話と同じ[声のインジケーター](../デザインシステム.md#共通コンポーネント設計案)と語を使い、録音中は自分の声（入力）、再生中は出力の段を見せる。機器名・数値・専門の行（録音入力元・再生出力先・メーターの数値）は出さない（Advancedの`Audio Check`だけに置く）。

| 状態 | 操作 | 状態の行 | footerの1文 |
|---|---|---|---|
| 待機 | 「5秒録音して再生」 | なし | なし |
| 開始できない | 「5秒録音して再生」（無効） | なし | 通話中は「音声チェックを使うには切断してください。」、Apple Watchが音声を使用中は「Apple Watchが音声を使用中です。この端末で音声チェックを始めるには、Apple Watchの音声を停止してください。」 |
| 準備中 | 「音声チェックを停止」 | `ProgressView`と「準備しています」 | — |
| 録音中 | 「音声チェックを停止」 | 「録音しています」と自分の声のインジケーター（`microphone.and.signal.meter`） | 話しかけてください。録音した声をこの後に再生します。 |
| 再生中 | 「音声チェックを停止」 | 「再生しています」と出力のインジケーター（`speaker.wave.3`） | 録音した声が聞こえれば、マイクとスピーカーは使えます。 |
| 完了 | 「5秒録音して再生」（やり直し） | 「音声チェックが終わりました」 | 聞こえなかったときは、音量と音声機器を確かめてください。 |
| 失敗 | 「5秒録音して再生」（やり直し） | 理由1文（例: マイクの音声を録音できませんでした。音声機器が変わりました） | — |

段が動かないときの意味は通話と同じ（録音中に動かない: マイクに入っていない。再生中に動くのに聞こえない: 音量・音声機器）。

#### 呼び出しの通知

2026-11-11の利用者指示により、通知の設定はOSの設定だけにする。設定タブに通知のSectionを置かず、相手の設定にも受け取りの切替を置かない。許可は初回の起動でOSの許可シートを1回だけ出す（[通知の許可を求める時点](../通知の設計.md#通知の許可を求める時点)）。通知が届くのは個人で登録している人からだけで、届けてほしくない人はユーザーから削除する。届いた通知の表示・鳴り方・「接続」「無視」のactionは[通知の設計](../通知の設計.md)に従う。1対1は相手を選ぶと接続と同時に1回通知し（[1対1で接続する](../操作の流れ.md#1対1で接続する)）、グループは会話中にメンバーの行の「呼び出す」で1人ずつ通知する。

### サインイン

テーマの背景グラデーションの上に、アプリアイコン（`ridecom.appicon`。ライト・ダークで切り替わる実際のアイコンの画像。大きく見せるため単色の`ridecom.glyph`は使わない）と`RideCom`の名前だけを置く。アプリの説明・キャッチコピーは置かない。画面下部の`SignInWithAppleButton`の直前に、サインインが必要な理由だけを1文で置く。

## Watch

### 前提

[Watch操作](../../spec/App/Watch操作.md)の範囲を維持し、接続先はiPhoneに保存済みの相手から選ぶ。[課題](../../backlog/README.md)の対象制限に合わせ、接続先は個人（1対1）だけを表示する。管理・設定はiPhoneに置く。

2026-11-01の利用者指示により、Watchのマイクは押している間だけ送話する操作に絞る。押していない間は常にマイクオフであり、「マイクオフ」の状態表示・マイクの切替ボタン・モード選択を画面に置かない。切断などの誤操作が困る操作は、手首を返したときに指が触れやすい画面下部へ置かず、上部へ置く。

### 画面構成

`NavigationStack`の2階層。通話中は通話画面を前面に固定し、戻る操作の代わりに左上を切断にする（`navigationBarBackButtonHidden`）。

| 画面 | 上部（`topBarLeading` / `topBarTrailing`） | 中央・下部 | 背景 |
|---|---|---|---|
| 接続先一覧 | 時刻のみ | 状態の1行（「iPhoneに接続済み」等）と保存済みの相手（個人）の行（[接続先のアバター](../デザインシステム.md#共通コンポーネント設計案)の人の記号）。行タップで開始（1対1ならiPhoneが相手へ通知を1回添える。[つながり方の前提](../操作の流れ.md#つながり方の前提)）。呼び出しの送信・取消の操作は置かない | rideBlueのグラデーション |
| 接続待ち | 左上に切断（確認付き） | 接続先の名前、`ProgressView`「接続中」 | rideBlue |
| 会話中 | 左上に切断（確認付き） | 接続先の名前と状態「会話中」（`waveform`の記号だけrideGreen）。その下、画面の下半分いっぱいに送話パネル | rideBlue |
| 切断の確認 | — | `confirmationDialog`「切断しますか？」と「切断」（destructive）・「キャンセル」 | 標準 |
| 音声停止・利用不能 | 左上に切断（確認付き） | 理由の文と「iPhoneを確認」の案内。送話パネルは無効表示 | 黒 |
| iPhone未接続 | 時刻のみ | `iphone.slash`、「iPhoneと接続できません」、再試行 | 黒 |
| サインアウト | 時刻のみ | 「iPhoneでRideComにサインインしてください」 | 黒 |

Apple Watchの送話は押している間だけなので、止まっている間（リフト・停車中など）の利用を想定する。走行中・滑走中の手を使わない会話は、iPhoneとヘッドセットの発話検出による送信で行う（[利用環境の前提](../デザインシステム.md#利用環境の前提)）。

「更新」ボタンは前面復帰で自動更新されるため一覧の末尾へ移す。注意書き「音声はApple Watchで話します。iPhoneを近くに置いてください。」は一覧のfooterに1回だけ置く。

### 誤操作を避ける配置

| 操作 | 位置と大きさ | 誤操作への対策 |
|---|---|---|
| 送話パネル | 画面の下半分、左右いっぱい。最も大きな操作対象 | 誤って触れても押している間だけ送話し、離せば必ず閉じる。通話を壊さない操作を最も触れやすい場所に置く |
| 切断 | 左上の`topBarLeading`。標準のツールバーボタンの大きさ | 送話パネルから最も遠い位置に置き、押すと確認を出す。確認の「切断」は`role: .destructive` |
| 呼び出しの取消 | 通話画面には置かず、一覧の行のスワイプ | 通話中の画面にパネル以外の操作を増やさない |

Digital Crownと`handGestureShortcut`には送話を割り当てない。押している間だけの操作と1回の操作は意味が異なり、離したことを確実に検出できないためである。

### 送話パネル

Appleのトランシーバーの大きな丸ボタンと区別するため、丸ではなく画面の角に沿った角丸の横長パネルにする。`Button`へ`.buttonBorderShape(.roundedRectangle)`と画面に沿う角丸（containerConcentric）を指定し、`.glassEffect`で塗る。

| 状態 | 見た目 | 文言・記号 | 触覚 |
|---|---|---|---|
| 待機（押していない） | rideBlueの淡いガラス。枠だけ明るい | `mic`と「押して話す」 | — |
| 押下中 | voice色で塗りつぶし、パネル上部に声のレベルを示す波形 | `waveform`と「話しています」 | 押下開始と解除で`.sensoryFeedback(.start / .stop)` |
| 準備中・応答待ち | 無効表示 | `ProgressView`と「準備中」 | — |
| 音声停止 | 無効表示 | 「音声停止中」 | — |

押下の検出は現行の`DragGesture(minimumDistance: 0)`を維持する。パネルの外へ指がずれた場合・画面が非アクティブになった場合も送話を閉じる現行の動作を保つ。視差効果を減らす設定では、押下時の拡大・波形の動きを止め、色と文言だけで示す。

## Widget

### 選択通話Widget（systemSmall）

配置時に選んだ相手・グループ専用のリモコン。現行の契約（設定先だけを開始、同じ設定先の通話中だけ切断・ミュート）を維持する。ミュートは`Toggle(isOn:intent:)`の切替ボタンで描き、現行と同じく反転ではなく指定した値（オン／オフ）を共通操作へ渡す。

| 状態 | 上段 | 中段 | 下段 |
|---|---|---|---|
| 未設定 | アプリ図形の小アイコン | 「長押しして接続先を設定」 | 「接続先を選ぶ」（Appを開く） |
| 待機 | 種別アイコン（`person.fill`／`person.3.fill`） | 接続先の名前（2行、`privacySensitive`）。つながっていない状態の語は出さない（[状態の表し方](../デザインシステム.md#状態の表し方)） | 「接続」（全幅の主要操作） |
| 接続待ち | 種別アイコン | 接続先の名前＋「接続中」（`ProgressView`だけwarning） | 「切断」（記号＋文字、glass・destructive） |
| 会話中 | 種別アイコン | 接続先の名前＋「会話中」（`waveform`の記号だけrideGreen） | 「ミュート」（1つの切替ボタン。記号は常に`mic.slash`、残りの幅いっぱい）と切断（ガラスの円に`Danger`の記号だけ。label「切断」。ミュート中の赤い塗りと見た目を分ける。右端に置き、ミュートとの間は[端末ごとの補足](../デザインシステム.md#端末ごとの補足)のWidgetの値） |
| ミュート中 | 種別アイコン | 接続先の名前＋「会話中」（`waveform`の記号だけrideGreen） | ミュートボタンがdangerで塗った選択状態になり「ミュート中」と表示。もう一度押すと戻る。切断は記号だけの円 |
| Apple Watchで操作中 | 種別アイコン | 接続先の名前＋「Apple Watchで操作中」（`applewatch`） | 切断だけ |

上段の右端には、すべての状態でアプリアイコンの小さな画像（`ridecom.appicon.small`。ライト・ダークの書き出し）を置く。ホーム画面で他のウィジェットと並んだときにRideComと分かるようにする。背景は`containerBackground`にテーマのグラデーション。色付き・クリア表示では背景が外れるため、接続先の名前と状態アイコンに`widgetAccentable()`を付け、主要操作は`.buttonStyle(.glassProminent)`、他は`.buttonStyle(.glass)`で外観に追従させる。状態は必ず文言でも示す。

| 項目 | 内容 |
|---|---|
| 構成 | 左に接続先の名前・状態、右に大きな操作ボタン（待機は「接続」、通話中は「ミュート」と「切断」）を縦に並べる。幅に余裕があるため切断も文字付きにする |
| 採否 | 現行は`systemSmall`だけ。CarPlay・StandByではsmallが使われるため、mediumは任意の追加候補として[改善候補](../../backlog/改善候補.md)で判断する |

### Live Activity・Dynamic Island

名前を出さない現行仕様を維持する。Dynamic Islandは表示が小さく、汎用の`waveform`や`phone`だけではどのアプリの通話か分からない。アプリアイコンの小さな画像（`ridecom.appicon.small`。暗い背景なのでDarkの書き出し）を、アプリを識別する位置（compactのleading・minimal・展開のleading）に使う（[アプリアイコンとカスタムシンボル](../アイコン定義.md#カスタムシンボル)）。

| 表示 | 構成 |
|---|---|
| ロック画面 | アプリアイコンの小さな画像と「RideCom」、状態文（会話中／接続中／音声停止中。ミュート中は通話のアクセサリと同じく「会話中・ミュート中」）だけ。「マイクオン」などの表示は置かない。切断ボタンは置かない。タップでアプリの通話のシートを開く（`rideintercom://call`） |
| 展開 | leading: アプリアイコンの小さな画像と「RideCom」、center: 状態文（記号だけ状態色）、trailing: マイク状態アイコン。切断は置かない |
| compact | leading: アプリアイコンの小さな画像、trailing: 状態。会話中は`mic`、ミュートは`mic.slash`（danger）、接続中は`ProgressView`（warning） |
| minimal | アプリアイコンの小さな画像（他のアプリと同時に表示される最小の円） |

2026-11-01の利用者指示により、ロック画面と展開表示から切断ボタンを外す。携帯をポケットやマウントに入れたまま、グローブで画面に触れることがあり、解除なしで押せる位置の切断は誤操作で接続を失うため。現行の[システム表示](../../spec/App/システム表示と通話操作.md#操作の所有者)はLive Activityの終了操作（`OpenCallControlIntent(action: .end)`）を持つので、採用時に同仕様から外す。切断はアプリ内・ウィジェット・Apple Watch・Siriから行う。

### Control・Macメニューバー

コントロールセンターの中では接続先を選ぶ画面を開けないため、Controlは選択通話Widget・HomeKitのControlと同じく、追加するときに接続先を選んでおく方式にする。Widget・Controlとも、接続先の設定の初期値は前回の接続先にする（App Intentの`defaultResult`）。追加した直後から使え、前回の接続先がない場合だけ「未設定」の表示になる（[入力欄と既定値](../デザインシステム.md#入力欄と既定値)）。`AppIntentControlConfiguration`とWidgetと共通の接続先選択（`SelectWidgetCallDestination`、保存ユーザー／通常グループ）を使う。

| 種類 | 状態 | 表示（記号・名前・値） | 押したとき |
|---|---|---|---|
| 接続先Control | 未設定 | `plus`・「接続先を設定」 | 長押しの編集で接続先を選ぶ案内（アプリを開く） |
| 接続先Control | 未接続 | `phone.fill`・接続先の名前・「接続」 | その接続先へ共通の開始操作。別の接続中は切り替えない（Widgetと同じ`allowSwitchingCall:false`） |
| 接続先Control | その接続先で接続中 | `waveform`・接続先の名前・「会話中」（色付きのON状態） | アプリの通話のシートを開く。切断はしない |
| 前回の接続先 | — | `arrow.clockwise`・「前回の接続先」 | 前回の接続先へ接続（現行の直近再開） |

Controlから切断しない理由: コントロールセンターはロック中も開けるため、[利用環境の前提](../デザインシステム.md#利用環境の前提)に従い取り消せない操作を置かない。Controlには画像を置けないため、記号はカスタムシンボル`ridecom.glyph`を薄い下地（hierarchicalのsecondary層）、操作の記号を前面の層にしたカスタムシンボル（例: `ridecom.glyph.phone`）として、他のアプリのControlと区別する。ロック中にも表示されるため、接続先の名前の表示可否は実装時にOSの秘匿表示の扱いと合わせて決める。

現行との差: 現行の[iOS Control](../../spec/App/システム表示と通話操作.md#操作の所有者)は「Choose a call」（通話画面を開く）と直近再開の2つ。前者を接続先を選んでおくControlに置き換える。

Macメニューバーは標準`MenuBarExtra`のメニュー表示を維持する。メニューバーのアイコンは、画像を置けないテンプレート描画のため、アプリを識別できるよう`ridecom.glyph`を基本とし、ミュート等の状態の表し方は未決事項とする。

## 画面ごとのUI Stackとレイアウト

[デザインシステムのUIスタック](../デザインシステム.md#uiスタック)の5状態を画面ごとに定める。ここにない状態は、その画面で起きない。配置の規則（幅・高さによる列数、安全領域、最大幅、固定する要素、寸法）は[レイアウトと画面サイズ](../デザインシステム.md#レイアウトと画面サイズ)に従い、下の表には各列に何を置くかだけを書く。

### 状態

| 画面 | Ideal | Empty（Blankを含む） | Loading | Partial | Error |
|---|---|---|---|---|---|
| 通話のシート | 会話中。ヒーロー・操作列・メンバー | 置かない（選ばれたときだけ開く） | 接続中（相手を待っています） | 一部のメンバーだけ接続、音声停止中（接続は維持） | 音声エラー、利用権・24時間条件で接続できない、別の端末で接続中。理由1文と復帰の操作 |

## 日本語の最適化

2026-11-01の利用者指摘により、日本語表示を英語の直訳ではなく日本語として最適化する。現行の`Localizable.xcstrings`（iPhone・Watch）とWidgetの日本語には、英語構文の直訳、iPhoneとWatchでの表記揺れ、全角ダッシュ「—」の多用、「Watch」「Widget」等の英字混在、技術用語（接続・保存済みユーザー）が残っている。英語を原文とする現行のString Catalog運用は維持し、日本語の値をこの規則で整える。

### 表記と組版の規則

| 対象 | 規則 | 理由 |
|---|---|---|
| ボタン | 動詞で終わる短い句、句点なし（「接続」「もう一度接続」）。ボタンのラベルは1行（`lineLimit(1)`）で、記号＋文字が収まる幅を確保する。収まらない狭い場所（小さいウィジェット等）では、意味が普遍的な操作（切断）だけを記号のみのボタンにしてaccessibility labelを付け、残りの幅を文字付きのボタンへ回す。文字を縮小（`minimumScaleFactor`）して詰め込まない | 操作の結果が一読で分かる。「ミュー／ト」のような語の途中の折り返しを防ぐ |
| 状態 | 体言止め（「会話中」「接続中」「ミュート中」） | 一瞬で読める長さにする |
| 補足・案内 | です・ます調の1文。理由と次の行動だけを書く | 説明を減らす |
| 状態と補足の区切り | 全角ダッシュ「—」で1行につなげず、状態（1行目）と補足（2行目）に分ける | 和文でダッシュは読みにくく、狭い画面で途中改行される |
| 英字 | 「インターネット」「ウィジェット」「ライブアクティビティ」「Apple Watch」とする。狭い表示で「Apple Watch」が入らない場合だけ記号`applewatch`と併記して省略する | Appleの日本語表記に合わせる |
| 用語の統一 | 同じ操作・状態はiPhone・Watch・ウィジェット・通知で同じ語にする（下表） | 端末ごとの揺れをなくす |
| 改行 | ボタン・状態・行タイトルは標準の文字サイズで1行に収まる長さにする。複数行になる案内文は、単語の途中で切れない位置で文を分けるか語を短くする。実機で文字サイズ最大まで確認する | 「再／開」「ませ／ん」のような分断を避ける |
| 字間・行間 | 和文に負の字間（`tracking`／`kerning`）を付けない。行間を詰めない（標準のDynamic Typeのまま） | 英字向けの詰めは和文を窮屈にする |
| 書体 | システムフォント（SF Pro＋ヒラギノ角ゴ）のまま。和文用の独自フォントを入れない | Dynamic Typeと太さの対応を保つ |
| 数字・単位 | 「4人」「3時間」「5分」。数字と単位の間に空白を入れない | 和文の慣用 |

## 実装の進め方

| 順序 | 内容 | 依存・完了条件 |
|---|---|---|
| カラー定義 | Asset CatalogのColorと`AppTheme.swift`の値を[カラーテーマ](../カラーテーマ.md)へ置換 | 既存UIテストが成功し、ライト／ダークの画面確認でコントラストを確認 |
| 構成と通話のシート | 通話タブを外し、Users・Groups・Settingsのタブと通話のシート・アクセサリへ再構成。ヒーロー・操作列・メンバー行を状態別に構成。サインイン直後の名前の入力を追加。識別子（`standardConnectButton`等）は維持 | 既存UIテストの識別子を変えない。状態ごとのスナップショットとVoiceOverの読み上げを確認 |
| ユーザー・グループ | 行の接続中の状態の語、編集のswipe移動、メンバーを招待（登録済みの人へは自動で届け、新しい人がいるときだけ共有画面）、招待中の行と招待の詳細 | 招待入口は[見直し課題](../../backlog/一般向け招待と利用制限・料金の見直し.md)の修正と同時に行う |
| 設定 | Sectionの並び替え | [Settings仕様](../../spec/App/UI/Settings.md)の識別子記載と`check_documentation.py`を更新 |
| 日本語 | [日本語の最適化](#日本語の最適化)の用語集と置き換え表を`Localizable.xcstrings`（App・Watch）とWidgetの文言へ適用 | 文字サイズ最大・最小のスクリーンショットで途中改行と切れを確認。英語表示が崩れないことも確認 |
| Watch | 一覧と通話画面の分離、送話パネル化、切断の上部移動と確認、マイク切替モードの画面からの除去 | Watchの対象を個人に限る課題と同時に行う。実Watchでの押下・触覚は未確認事項へ |
| Widget・Control・Live Activity | Widgetの状態別の配置・アイコン図形・containerBackground・`widgetAccentable`。Controlの接続先設定とカスタムシンボル。ライブアクティビティとDynamic Islandから切断を外す | 色付き・クリア・StandBy・CarPlay・コントロールセンターの表示を確認。現行のLive Activity終了操作とControlの仕様を同じ変更で更新 |

各工程は既存の識別子・accessibility label/valueを保護する回帰テストを先に確認してから変更する（[開発方針](../../policies/開発方針.md#実装と検証)）。
