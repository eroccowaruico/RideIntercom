# RideCom 画面構成とレイアウト

## 指示と背景

2026-11-01の利用者指示により、一般向け画面（Standard）・Watch・Widgetの画面構成とレイアウトを設計する。Apple HIGと標準のSwiftUI部品だけで組む方針は維持し、そのうえで最低限の配色・情報の優先度・状態ごとの見え方を整える。[一般向け招待と利用制限の見直し](../../backlog/一般向け招待と利用制限・料金の見直し.md#一般向け画面のデザインは後続)で後回しにしていたデザインの設計案にあたる。

本書は実装前の設計案。現行の項目・識別子・発現条件は[Call画面](../../spec/App/UI/Call.md)、[Settings画面](../../spec/App/UI/Settings.md)、[Watch操作](../../spec/App/Watch操作.md)、[システム表示と通話操作](../../spec/App/システム表示と通話操作.md)を正本とし、実装と同じ変更でそれらを更新する。配色は[カラーテーマ](../カラーテーマ.md)、見た目は[デザイン見本](デザイン見本.html)を参照する。Advancedの診断画面は対象外とし、テーマのtintだけが反映される。

## 現行UIの調査結果

| 対象 | 現在の構成 | 問題 |
|---|---|---|
| 色 | `AppColorPalette`がシステム色のみ。`AccentColor`は値なし。Call背景は`secondary.opacity(0.08)` | 製品の色がなく、標準の青と灰色だけ。状態色と声のメーターが同じ緑・青を共有する |
| Standard Call | 1つの`List`に直近通話・現在通話・保存エラー・宛先名（title2）・状態文・接続・招待・音声Section・通知・メンバーを順に積む | 主操作（接続／終了）が文字だけのボタンで、状態・宛先名と視覚的にまとまらない。マイクとスピーカーのミュートがToggleで、通話中の最重要操作に見えない。状態がテキスト1行で、色・アイコンがない |
| Standard Users / Groups | `Label`のボタン行。編集は行末の鉛筆ボタン | 行の情報が名前だけ。現在通話中の相手・グループが一覧で分からない。招待の入口がない |
| Settings | 単一Formに多数のSection | 一般向けの見出しの粒度は概ね妥当。並び順が利用頻度と一致しない |
| サインイン | 標準ScrollViewに説明とSign in with Apple | ブランドの第一印象がない |
| Watch | 1つの`List`に状態・Picker・押して話すボタン・終了・更新・呼出し・通話先一覧・注意書きを縦積み | 通話中に押して話すボタンが小さく、モードPickerや一覧と同じ画面に混在する。通話先一覧が下部に埋もれる。状態に色・アイコンがない |
| 選択通話Widget | `systemSmall`のみ。`RideCom`見出し・名前・`.bordered`ボタンを縦積み。背景`.fill.tertiary` | 状態が小さな文字だけ。通話中の操作がアイコンのみで意味が弱い。ブランド色がなく、色付き・クリア表示での見え方が考慮されていない |
| Live Activity | `phone.fill`と状態文・マイク状態・終了ボタン | 配色の指定なし。Dynamic Islandに声・ミュートの区別が弱い |

## 共通の設計方針

| 方針 | 内容 |
|---|---|
| Liquid Glassの適用（必須） | すべての対象画面でLiquid Glassを適用することを条件とする。タブバー・ツールバー・sheet・メニューはOS標準のガラスをそのまま使い、独自の背景で覆わない（`toolbarBackground`で不透明化しない）。主要操作は`.buttonStyle(.glassProminent)`、補助操作は`.buttonStyle(.glass)`、隣接する円形ボタン群は`GlassEffectContainer`でまとめ、カード状の面は`.glassEffect`を使う。Watchは`containerBackground`とガラスのボタン、Widgetは色付き・クリア表示でのガラス描画、アプリアイコンは`.icon`のLiquid Glassレイヤーを使う。「透明度を下げる」設定ではOSが不透明化した状態で成立させる。独自のblur・半透明色・光沢の描画で代用しない |
| 1画面1主操作 | 各状態で最も重要な操作を1つだけ`glassProminent`にする。未接続は「接続」、音声停止は「音声を再開」。会話中は塗りの主操作を置かず、ミュートの選択状態と切断だけを色で示す |
| 操作と状態の記号 | 操作ボタンの記号は操作の意味を表す（ミュートは常に`mic.slash`の切替ボタン、切断は`phone.down.fill`）。「ミュート解除」のような反対操作の別ボタンを作らない。状態表示の記号は今の状態を表す（オンは`mic`、ミュート中は`mic.slash`）。同じ場所で両者を混ぜない |
| 状態は3点で示す | 色＋SF Symbols＋文言。`callStatusIcon`の意味は[アイコン定義](../アイコン定義.md)に従う |
| 利用環境の前提 | 走行中・滑走中は手で操作しない。接続は出発前に済ませ、走行中は操作なしで会話が続くことを主な体験とする。操作は止まっている間だけ、携帯を取り出さずに、グローブをしたまま行う前提で設計する（[デザインシステム](../デザインシステム.md#利用環境の前提)）。端末を解除せずに触れられる表示に取り消せない操作を置かない |
| 通話中の操作は大きく | iPhoneのミュート・スピーカー・切断は円形のガラスボタン（64pt）、Watchの送話は画面の下半分いっぱいのパネル。グローブ・揺れの中でも押せる大きさにする |
| 接続先は名前を主役に | 接続先の名前を最上部の大きな見出しにし、種別（ユーザー／グループ）と人数を補助に置く |
| 診断を出さない | 経路名は「近距離」「インターネット」の短い補助表示だけ。codec・ID・数値はAdvancedへ |
| 標準部品だけ | `List`・`Section`・`Button`・`Toggle`・`Slider`・`Label`・`ContentUnavailableView`・`ProgressView`・`ShareLink`・`glassEffect`／`glass`系buttonStyle。独自のShape描画・独自アニメーションを作らない |
| 適応 | Dynamic Type、VoiceOver、ライト／ダーク、透明度を下げる、視差効果を減らす、iPad regular width、macOSのwindowサイズ変更で同じ構造を保つ |

## iPhone・iPad・Mac（Standard）

### タブ構成

現行の4タブを維持し、名前とSF Symbolsを揃える。採用時は[アイコン適用](../../spec/App/UI/アイコン適用.md)のタブの記号を同じ変更で更新する。iPadとMacでは`.tabViewStyle(.sidebarAdaptable)`によりサイドバーへ自動で切り替える。

| タブ | 表示名 | SF Symbol | 役割 |
|---|---|---|---|
| Call | 通話 | `phone.fill` | 現在または選択中の接続を操作する主画面。2026-11-01の利用者指示で、操作語を「接続／切断」に統一した後もタブ名は「通話」のまま |
| Users | ユーザー | `person.2.fill` | 1対1の相手を選ぶ。招待の入口 |
| Groups | グループ | `person.3.fill` | 通常グループを選ぶ・作る |
| Settings | 設定 | `gearshape.fill` | 利用前の調整 |

通話中は`TabView`の`tabViewBottomAccessory`に現在通話のミニ表示（接続先の名前・状態の記号・ミュートの切替ボタン）を置き、どのタブからでも通話へ戻れるようにする。現行の`CurrentCallSection`の役割をこの表示へ移す。

### 通話タブの状態別構成

画面は上から「状態把握（ヒーロー）> 主要操作 > 対象一覧 > 補助情報」の順に積む。背景はテーマのグラデーション、コンテナは`List(.insetGrouped)`で、ヒーローは`listRowBackground(.clear)`の行として置く。

| 状態 | ヒーロー | 主要操作 | 一覧・補助 |
|---|---|---|---|
| 未選択（Blank） | `ContentUnavailableView`「接続先を選んでください」（説明文なし）とアプリのアイコン図形 | 前回の接続先がある場合「もう一度接続」（prominent）。続けて「ユーザーを選ぶ」「グループを選ぶ」（glass） | 前回の接続先の接続先の名前と種別 |
| 選択・未接続 | 種別ラベル（例: グループ・4人）、接続先の名前（largeTitle相当のtitle太字）、状態「未接続」（neutral・`phone`） | 「接続」（prominent・全幅）。他の通話中は「この通話に切り替え」 | メンバー一覧（名前だけ）、招待中の人と再共有、メンバーを追加（グループのみ） |
| 接続待ち（Loading） | 状態「接続中」（`ProgressView`だけwarning）と補足「相手の参加を待っています」 | 「キャンセル」（glass・destructive） | メンバー一覧。接続済みの人から状態が変わる |
| 会話中（Ideal） | 状態「会話中」（文字は標準色、`waveform`の記号だけrideGreen）、補助に経路「近距離・インターネット」 | 円形3ボタン: ミュート（glass、記号は常に`mic.slash`。ミュート中はdangerで塗った選択状態と「ミュート中」）、スピーカー（glass）、切断（danger prominent） | スピーカー音量Slider、メンバー一覧（話している人にvoiceのメーター）、招待中の人と再共有 |
| 音声停止（Partial） | 状態「音声停止中」（`headphones`の記号だけwarning）と理由の1文 | 「音声を再開」（prominent） | 接続は維持していることを補助文で示す。メンバー一覧は維持 |
| エラー（Error） | 状態「音声エラー」（`exclamationmark.triangle.fill`の記号だけdanger） | 再試行がある場合だけその操作 | エラー本文（`textPrimary`）はヒーロー直下に1か所だけ |
| Apple Watchで操作中 | 状態は通常どおり | ミュートボタンの代わりに「マイクはApple Watchで操作」（`applewatch`、操作不可の表示） | スピーカー・切断は通常どおり |

#### 会話中の配置

| 領域 | 内容 | 部品 |
|---|---|---|
| ヒーロー | 種別・人数 / 接続先の名前 / 状態アイコン＋状態文 / 経路の補助文 | `VStack`内の`Text`・`Label`。全体を1つのaccessibility要素にし、valueへ状態と経路を渡す |
| 操作列 | ミュート・スピーカー・切断の3ボタン。各ボタンの下に短い文言（「ミュート」「スピーカー」「切断」）。ミュートは1つの切替ボタンとし、記号は常に`mic.slash`。ミュート中は選択状態（dangerの塗り）と「ミュート中」で示し、「ミュート解除」という別ボタンを作らない | `Button`＋`.buttonStyle(.glassProminent / .glass)`＋`.buttonBorderShape(.circle)`＋`.controlSize(.extraLarge)`。`GlassEffectContainer`でまとめる |
| 音量 | スピーカー音量（0〜200%、100%超はブースト表示）と、対応端末だけ「声を分離」のToggle | `Slider`の`minimumValueLabel`／`maximumValueLabel`に`speaker`／`speaker.wave.3` |
| メンバー | 行: 人物アイコン、名前、話している間だけvoice色の波形アイコン、行末に音量%。タップで個別音量Sliderを展開 | `DisclosureGroup`。名前編集はswipeとcontextMenuへ移す |
| 補助 | 招待中の人の再共有、メンバーを追加（グループのみ） | 行内の`ShareLink`、`Button`とsheet。[招待と共有](#招待と共有)に従い、汎用の共有ボタンは置かない |

アクセシビリティ: ミュートボタンはlabel「ミュート」、ミュート中は`isSelected`のtraitとvalue「オン」。話者アイコンはlabel「話しています」。色だけで話者を示さない。

### 招待と共有

RideComの共有は、メンバーを指定した招待である。共有画面は「メンバーを追加する」操作の一部として開き、共有だけを独立した操作として画面に置かない。

| 場面 | 操作の流れ | 表示 |
|---|---|---|
| グループにメンバーを追加 | 通話画面の「メンバーを追加」→ sheetでユーザーを選ぶ、または「新しい人を招待」→「追加して招待を送る」で確定 → その人宛ての招待で`ShareLink`の共有画面を自動で開く | 追加した人は「招待中」Sectionへ入り、参加が成立した時点でメンバー一覧へ移る |
| 新しい相手（1対1）を追加 | ユーザータブの`+` → 確定 → 直接招待の共有画面を自動で開く | ユーザータブの「招待中」Sectionへ入る |
| 招待が届かなかった・期限切れ | 「招待中」の行の「再共有」 → 同じ相手宛ての新しい招待で共有画面を開く | 再共有は招待中の行にだけ置く。参加済みの人・通話画面の上部には置かない |
| 招待の取消 | 「招待中」の行のswipe／contextMenuで削除 | 確認付きの破壊操作 |

共有画面を閉じた・共有が完了しただけでは参加とみなさない（[招待の見直し](../../backlog/一般向け招待と利用制限・料金の見直し.md#一般向け画面の招待と復旧)）。相手が招待から参加し、本人を識別できた時点でメンバー・ユーザーとして確定する。

現行仕様との差: 通常groupの招待URLは宛先を持たず所持者が使える（[通信仕様](../../spec/App/通信仕様.md)）。この画面の流れは宛先指定のメンバー招待と参加成立後の確定を前提とするため、実装時に招待形式と保存の扱いを[見直し課題](../../backlog/一般向け招待と利用制限・料金の見直し.md)と合わせて決める。

### 設定タブ（Standard）

grouped Formを維持し、同じ目的のSectionを隣り合わせたグループにまとめる。グループの切れ目はSection間より少し広い余白で区切り、グループ名そのものは画面に出さない（Formの標準外の見出しを作らない）。日常的に触る項目を上に、まれに使う表示切替と専門設定を下に、リセットを最下部に独立して置く。背景グラデーションは適用しない。見た目は[デザイン見本](デザイン見本.html#settings)の「設定の構成」を参照する。

| グループ | Section（表示名） | 項目 | footer |
|---|---|---|---|
| 自分 | アカウント | Appleでログイン済み、サインアウト、アカウントを削除（赤・最後） | — |
| 自分 | 自分の表示名 | 名前（編集） | グループの相手に伝える名前です。相手は自分の端末で別の呼び名を付けられます。 |
| 自分 | 利用権 | 利用権の状態、購入を復元、購入内容を見る | — |
| 接続 | 自動切断 | 通常の接続、Apple Watchから開始した接続 | 次に接続するときから適用します。 |
| 接続 | 呼び出しの通知 | 状態、通知を有効にする／確認／無効にする | — |
| 接続 | 接続状態の表示 | ロック画面に接続状態を表示（Macはメニューバーに表示） | — |
| 通信 | インターネット接続 | 状態、インターネット接続を設定（sheet） | — |
| 通信 | 通信経路 | 主画面では状態（例: 近距離・インターネット）だけを表示し、「›」で通信経路の画面へ。2つのスイッチを主画面に並べない | — |
| 音声 | 音声の入出力 | 入力、出力、送信する声を分離 | — |
| 音声 | 発話検出 | 感度（静かな場所／標準／騒がしい場所） | 周りの音が大きいときは「騒がしい場所」にします。 |
| 音声 | 音声チェック | 5秒録音して再生 | — |
| 高度な設定 | 開発者向けの高度な設定 | NavigationLinkの1行だけ | — |
| リセット | リセット | すべての設定をリセット（赤・確認付き） | 音声と接続の設定を初期値に戻します。グループ・ユーザー・ログインは変わりません。 |

通信経路の画面は、2つのスイッチと説明だけを置く。主画面で誤ってOFFにしないよう、1階層下へ分ける。

| 項目 | 説明（補足行） | footer |
|---|---|---|
| 近距離 | 圏外でも近くの仲間と直接つながります | どちらか1つは必要です。変更すると接続し直します。 |
| インターネット | 離れた仲間とつながります | 同上 |

「開発者向けの高度な設定」の画面には、画面表示（標準／詳細）の切替と専門的な音声の設定を置く。一般の利用者が入らないよう項目名を専門的な語にし、画面の一番上に警告を出す。音声の項目は将来、固定して利用者が変更できないようにする想定であり、一般向けに残す調整（発話検出の感度）は主画面へ出す。リセットはここに置かず、設定の最下部の1か所だけにする。

| 位置 | Section（表示名） | 項目 | footer |
|---|---|---|---|
| 一番上 | 警告 | 見出し「通常は変更しないでください」と本文「ここの設定を変えると、音声や接続が正しく動かなくなることがあります。初期値以外の組み合わせはテストしていません。」（注意の記号と`warning`の淡い面） | — |
| 1 | 画面表示 | 標準／詳細 | 詳細表示では診断と細かな設定を表示します（英語のみ）。 |
| 2 | オーディオセッション | セッションモード（バースト／ストリーム）、スピーカー出力を強制、エコーキャンセレーション、他のアプリ音声のダッキング | バーストは通常の音声モード、ストリームは電話に近い会話向けです。 |
| 3 | 送信コーデック | 形式（PCM／AAC-ELD／Opus）、サンプリング周波数、エンコードビットレート（音質低下の候補を明示） | 使えない形式は自動で切り替わります。 |

現行との差: 現行は画面表示が先頭、リセット・通信経路・発話検出は「More Audio and Connection Settings」の中にあり、その中の語は日本語訳がない。一般向けではリセット・通信経路（状態表示と1階層下の設定）・発話検出を設定の主画面へ出し、画面表示の切替は「開発者向けの高度な設定」の中へ移す。その中の語も日本語化する。破壊的な操作（アカウントを削除・すべての設定をリセット）は各グループの最後に赤で置き、標準の確認を出す。

### サインイン

テーマの背景グラデーションの上に、アプリのアイコン図形と`RideCom`の名前だけを置く。アプリの説明・キャッチコピーは置かない。画面下部の`SignInWithAppleButton`の直前に、サインインが必要な理由だけを1文で置く。

| 位置 | 内容 |
|---|---|
| 上〜中央 | アイコン図形、`RideCom` |

## Watch

### 前提

[Watch操作](../../spec/App/Watch操作.md)の範囲を維持し、接続先はiPhoneに保存済みの相手から選ぶ。[課題](../../backlog/README.md)の対象制限に合わせ、接続先は個人（1対1）だけを表示する。管理・設定はiPhoneに置く。

2026-11-01の利用者指示により、Watchのマイクは押している間だけ送話する操作に絞る。押していない間は常にマイクオフであり、「マイクオフ」の状態表示・マイクの切替ボタン・モード選択を画面に置かない。切断などの誤操作が困る操作は、手首を返したときに指が触れやすい画面下部へ置かず、上部へ置く。

### 画面構成

`NavigationStack`の2階層。通話中は通話画面を前面に固定し、戻る操作の代わりに左上を切断にする（`navigationBarBackButtonHidden`）。

| 画面 | 上部（`topBarLeading` / `topBarTrailing`） | 中央・下部 | 背景 |
|---|---|---|---|
| 接続先一覧 | 時刻のみ | 状態の1行（「iPhoneに接続済み」等）と保存済みの相手の行。行タップで開始。呼出し通知は行の長押しメニュー | rideBlueのグラデーション |
| 接続待ち | 左上に切断（確認付き） | 接続先の名前、`ProgressView`「接続中」 | rideBlue |
| 会話中 | 左上に切断（確認付き） | 接続先の名前と状態「会話中」（`waveform`の記号だけrideGreen）。その下、画面の下半分いっぱいに送話パネル | rideBlue |
| 切断の確認 | — | `confirmationDialog`「切断しますか？」と「切断」（destructive）・「キャンセル」 | 標準 |
| 音声停止・利用不能 | 左上に切断（確認付き） | 理由の文と「iPhoneを確認」の案内。送話パネルは無効表示 | 黒 |
| iPhone未接続 | 時刻のみ | `iphone.slash`、「iPhoneと接続できません」、再試行 | 黒 |
| サインアウト | 時刻のみ | 「iPhoneでRideComにサインインしてください」 | 黒 |

Apple Watchの送話は押している間だけなので、止まっている間（リフト・停車中など）の利用を想定する。走行中・滑走中の手を使わない会話は、iPhoneとヘッドセットの発話検出による送信で行う（[利用環境の前提](../デザインシステム.md#利用環境の前提)）。

「更新」ボタンは前面復帰で自動更新されるため一覧の末尾へ移す。注意書き「音声はApple Watchで話します。iPhoneを近くに置いてください。」は一覧のfooterに1回だけ置く。

### 誤操作を避ける配置

| 操作 | 位置と大きさ | 誤操作への対策 |
|---|---|---|
| 送話パネル | 画面の下半分、左右いっぱい。最も大きな操作対象 | 誤って触れても押している間だけ送話し、離せば必ず閉じる。通話を壊さない操作を最も触れやすい場所に置く |
| 切断 | 左上の`topBarLeading`。標準のツールバーボタンの大きさ | 送話パネルから最も遠い位置に置き、押すと確認を出す。確認の「切断」は`role: .destructive` |
| 呼出し通知の取消 | 通話画面には置かず、一覧の長押しメニュー | 通話中の画面にパネル以外の操作を増やさない |

Digital Crownと`handGestureShortcut`には送話を割り当てない。押している間だけの操作と1回の操作は意味が異なり、離したことを確実に検出できないためである。

### 送話パネル

Appleのトランシーバーの大きな丸ボタンと区別するため、丸ではなく画面の角に沿った角丸の横長パネルにする。`Button`へ`.buttonBorderShape(.roundedRectangle)`と画面に沿う角丸（containerConcentric）を指定し、`.glassEffect`で塗る。

| 状態 | 見た目 | 文言・記号 | 触覚 |
|---|---|---|---|
| 待機（押していない） | rideBlueの淡いガラス。枠だけ明るい | `mic`と「押して話す」 | — |
| 押下中 | voice色で塗りつぶし、パネル上部に声のレベルを示す波形 | `waveform`と「話しています」 | 押下開始と解除で`.sensoryFeedback(.start / .stop)` |
| 準備中・応答待ち | 無効表示 | `ProgressView`と「準備中」 | — |
| 音声停止 | 無効表示 | 「音声停止中」 | — |

押下の検出は現行の`DragGesture(minimumDistance: 0)`を維持する。パネルの外へ指がずれた場合・画面が非アクティブになった場合も送話を閉じる現行の動作を保つ。視差効果を減らす設定では、押下時の拡大・波形の動きを止め、色と文言だけで示す。

## Widget

### 選択通話Widget（systemSmall）

配置時に選んだ相手・グループ専用のリモコン。現行の契約（設定先だけを開始、同じ設定先の通話中だけ切断・ミュート）を維持する。ミュートは`Toggle(isOn:intent:)`の切替ボタンで描き、現行と同じく反転ではなく指定した値（オン／オフ）を共通操作へ渡す。

| 状態 | 上段 | 中段 | 下段 |
|---|---|---|---|
| 未設定 | アプリ図形の小アイコン | 「長押しして接続先を設定」 | 「接続先を選ぶ」（Appを開く） |
| 待機 | 種別アイコン（`person.fill`／`person.3.fill`） | 接続先の名前（2行、`privacySensitive`）＋「未接続」 | 「接続」（全幅、glassProminent） |
| 接続待ち | 種別アイコン | 接続先の名前＋「接続中」（`ProgressView`だけwarning） | 「切断」（記号＋文字、glass・destructive） |
| 会話中 | 種別アイコン | 接続先の名前＋「会話中」（`waveform`の記号だけrideGreen） | 「ミュート」（1つの切替ボタン。記号は常に`mic.slash`、残りの幅いっぱい）と切断（dangerの記号だけの44pt円、accessibility label「切断」） |
| ミュート中 | 種別アイコン | 接続先の名前＋「会話中」（`waveform`の記号だけrideGreen） | ミュートボタンがdangerで塗った選択状態になり「ミュート中」と表示。もう一度押すと戻る。切断は記号だけの44pt円 |
| Apple Watchで操作中 | 種別アイコン | 接続先の名前＋「Apple Watchで操作中」（`applewatch`） | 切断だけ |

上段の右端には、すべての状態でアプリのアイコン図形（`ridecom.glyph`、角丸の小さなタイル）を置く。ホーム画面で他のウィジェットと並んだときにRideComと分かるようにする。背景は`containerBackground`にテーマのグラデーション。色付き・クリア表示では背景が外れるため、接続先の名前と状態アイコンに`widgetAccentable()`を付け、主要操作は`.buttonStyle(.glassProminent)`、他は`.buttonStyle(.glass)`で外観に追従させる。状態は必ず文言でも示す。

### 追加候補（systemMedium）

| 項目 | 内容 |
|---|---|
| 構成 | 左に接続先の名前・状態、右に大きな操作ボタン（待機は「接続」、通話中は「ミュート」と「切断」）を縦に並べる。幅に余裕があるため切断も文字付きにする |
| 採否 | 現行は`systemSmall`だけ。CarPlay・StandByではsmallが使われるため、mediumは任意の追加候補として[改善候補](../../backlog/改善候補.md)で判断する |

### Live Activity・Dynamic Island

名前を出さない現行仕様を維持する。Dynamic Islandは表示が小さく、汎用の`waveform`や`phone`だけではどのアプリの通話か分からない。アプリアイコンの図形（道とシュプール＋音声波形）から作るカスタムシンボル`ridecom.glyph`を、アプリを識別する位置（compactのleading・minimal・展開のleading）に使う。

| 表示 | 構成 |
|---|---|
| ロック画面 | `ridecom.glyph`と「RideCom」、状態文（会話中／接続中／音声停止中）、マイク状態だけ。切断ボタンは置かない。タップでアプリの通話タブを開く（`rideintercom://call`） |
| 展開 | leading: `ridecom.glyph`と「RideCom」、center: 状態文（記号だけ状態色）、trailing: マイク状態アイコン。切断は置かない |
| compact | leading: `ridecom.glyph`、trailing: 状態。会話中は`mic`、ミュートは`mic.slash`（danger）、接続中は`ProgressView`（warning） |
| minimal | `ridecom.glyph`（他のアプリと同時に表示される最小の円） |

2026-11-01の利用者指示により、ロック画面と展開表示から切断ボタンを外す。携帯をポケットやマウントに入れたまま、グローブで画面に触れることがあり、解除なしで押せる位置の切断は誤操作で接続を失うため。現行の[システム表示](../../spec/App/システム表示と通話操作.md#操作の所有者)はLive Activityの終了操作（`OpenCallControlIntent(action: .end)`）を持つので、採用時に同仕様から外す。切断はアプリ内・ウィジェット・Apple Watch・Siriから行う。

#### カスタムシンボル

| 項目 | 内容 |
|---|---|
| 作成 | `RideIntercom/AppIcon.icon/Assets`の`Road.svg`と`Waveform.svg`から、SF Symbolsアプリのカスタムシンボル（テンプレートを書き出して図形を配置）として作る。図形の輪郭はアプリアイコンと同じにし、細部は小さいサイズで潰れない範囲に整える |
| レイヤー | 道とシュプールを第1、音声波形を第2のレイヤーにする。`symbolRenderingMode(.palette)`で道をrideBlueの明るい値、波形をvoiceで描く。monochromeでも形で識別できること |
| 配置 | Widget extensionのAsset Catalogに置き、`Image("ridecom.glyph")`で参照する。App本体で使う場合（Macメニューバー等）は同じ資産を共有する |
| 使う場所 | Dynamic Island（leading・minimal）、ロック画面のLive Activity、Widgetの未設定表示の小アイコン。Macメニューバーの表示も同じ理由で候補とし、状態はバッジ付きの派生（ミュート等）で示すかを実装時に決める |
| 使わない場所 | アプリ内の操作ボタン・状態表示。アプリ内の意味はSF Symbolsの[アプリ内アイコン定義](../アイコン定義.md)に従い、ブランド図形を操作の記号として使わない |

### Control・Macメニューバー

コントロールセンターの中では接続先を選ぶ画面を開けないため、Controlは選択通話Widget・HomeKitのControlと同じく、追加するときに接続先を選んでおく方式にする。`AppIntentControlConfiguration`とWidgetと共通の接続先選択（`SelectWidgetCallDestination`、保存ユーザー／通常グループ）を使う。

| 種類 | 状態 | 表示（記号・名前・値） | 押したとき |
|---|---|---|---|
| 接続先Control | 未設定 | `plus`・「接続先を設定」 | 長押しの編集で接続先を選ぶ案内（アプリを開く） |
| 接続先Control | 未接続 | `phone.fill`・接続先の名前・「接続」 | その接続先へ共通の開始操作。別の接続中は切り替えない（Widgetと同じ`allowSwitchingCall:false`） |
| 接続先Control | その接続先で接続中 | `waveform`・接続先の名前・「会話中」（色付きのON状態） | アプリの通話タブを開く。切断はしない |
| 前回の接続先 | — | `arrow.clockwise`・「前回の接続先」 | 前回の接続先へ接続（現行の直近再開） |

Controlから切断しない理由: コントロールセンターはロック中も開けるため、[利用環境の前提](../デザインシステム.md#利用環境の前提)に従い取り消せない操作を置かない。記号はアイコン図形を薄い下地（hierarchicalのsecondary層）、操作の記号を前面の層にしたカスタムシンボル（例: `ridecom.glyph.phone`）として、他のアプリのControlと区別する。ロック中にも表示されるため、接続先の名前の表示可否は実装時にOSの秘匿表示の扱いと合わせて決める。

現行との差: 現行の[iOS Control](../../spec/App/システム表示と通話操作.md#操作の所有者)は「Choose a call」（通話画面を開く）と直近再開の2つ。前者を接続先を選んでおくControlに置き換える。

Macメニューバーは標準`MenuBarExtra`のメニュー表示を維持する。メニューバーのアイコンは、アプリを識別できるよう`ridecom.glyph`を基本とし、ミュート等の状態の表し方は未決事項とする。

## 日本語の最適化

2026-11-01の利用者指摘により、日本語表示を英語の直訳ではなく日本語として最適化する。現行の`Localizable.xcstrings`（iPhone・Watch）とWidgetの日本語には、英語構文の直訳、iPhoneとWatchでの表記揺れ、全角ダッシュ「—」の多用、「Watch」「Widget」等の英字混在、技術用語（接続・保存済みユーザー）が残っている。英語を原文とする現行のString Catalog運用は維持し、日本語の値をこの規則で整える。

### 表記と組版の規則

| 対象 | 規則 | 理由 |
|---|---|---|
| ボタン | 動詞で終わる短い句、句点なし（「接続」「もう一度接続」）。ボタンのラベルは1行（`lineLimit(1)`）で、記号＋文字が収まる幅を確保する。収まらない狭い場所（小さいウィジェット等）では、意味が普遍的な操作（切断）だけを記号のみのボタンにしてaccessibility labelを付け、残りの幅を文字付きのボタンへ回す。文字を縮小（`minimumScaleFactor`）して詰め込まない | 操作の結果が一読で分かる。「ミュー／ト」のような語の途中の折り返しを防ぐ |
| 状態 | 体言止め（「会話中」「接続中」「ミュート中」） | 一瞬で読める長さにする |
| 補足・案内 | です・ます調の1文。理由と次の行動だけを書く | 説明を減らす |
| 状態と補足の区切り | 全角ダッシュ「—」で1行につなげず、状態（1行目）と補足（2行目）に分ける | 和文でダッシュは読みにくく、狭い画面で途中改行される |
| 英字 | 「インターネット」「ウィジェット」「ライブアクティビティ」「Apple Watch」とする。狭い表示で「Apple Watch」が入らない場合だけ記号`applewatch`と併記して省略する | Appleの日本語表記に合わせる |
| 用語の統一 | 同じ操作・状態はiPhone・Watch・ウィジェット・通知で同じ語にする（下表） | 端末ごとの揺れをなくす |
| 改行 | ボタン・状態・行タイトルは標準の文字サイズで1行に収まる長さにする。複数行になる案内文は、単語の途中で切れない位置で文を分けるか語を短くする。実機で文字サイズ最大まで確認する | 「再／開」「ませ／ん」のような分断を避ける |
| 字間・行間 | 和文に負の字間（`tracking`／`kerning`）を付けない。行間を詰めない（標準のDynamic Typeのまま） | 英字向けの詰めは和文を窮屈にする |
| 書体 | システムフォント（SF Pro＋ヒラギノ角ゴ）のまま。和文用の独自フォントを入れない | Dynamic Typeと太さの対応を保つ |
| 数字・単位 | 「4人」「3時間」「5分」。数字と単位の間に空白を入れない | 和文の慣用 |

### 用語集

| 概念 | 使う語 | 使わない語 |
|---|---|---|
| 接続を始める | 接続 | 通話を開始、かける（電話ではないため） |

## 実装の進め方

| 順序 | 内容 | 依存・完了条件 |
|---|---|---|
| カラー定義 | Asset CatalogのColorと`AppTheme.swift`の値を[カラーテーマ](../カラーテーマ.md)へ置換 | 既存UIテストが成功し、ライト／ダークの画面確認でコントラストを確認 |
| 通話タブ | ヒーロー・操作列・メンバー行を状態別に再構成。識別子（`standardConnectButton`等）は維持 | 既存UIテストの識別子を変えない。状態ごとのスナップショットとVoiceOverの読み上げを確認 |
| ユーザー・グループ | 行の通話中表示、編集のswipe移動、メンバー追加と同時の招待共有、招待中の表示と再共有 | 招待入口は[見直し課題](../../backlog/一般向け招待と利用制限・料金の見直し.md)の修正と同時に行う |
| 設定 | Sectionの並び替え | [Settings仕様](../../spec/App/UI/Settings.md)の識別子記載と`check_documentation.py`を更新 |
| 日本語 | [日本語の最適化](#日本語の最適化)の用語集と置き換え表を`Localizable.xcstrings`（App・Watch）とWidgetの文言へ適用 | 文字サイズ最大・最小のスクリーンショットで途中改行と切れを確認。英語表示が崩れないことも確認 |
| Watch | 一覧と通話画面の分離、送話パネル化、切断の上部移動と確認、マイク切替モードの画面からの除去 | Watchの対象を個人に限る課題と同時に行う。実Watchでの押下・触覚は未確認事項へ |
| Widget・Control・Live Activity | Widgetの状態別の配置・アイコン図形・containerBackground・`widgetAccentable`。Controlの接続先設定とカスタムシンボル。ライブアクティビティとDynamic Islandから切断を外す | 色付き・クリア・StandBy・CarPlay・コントロールセンターの表示を確認。現行のLive Activity終了操作とControlの仕様を同じ変更で更新 |

各工程は既存の識別子・accessibility label/valueを保護する回帰テストを先に確認してから変更する（[開発方針](../../policies/開発方針.md#実装と検証)）。
