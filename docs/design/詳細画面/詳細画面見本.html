相手ごとの条件が、1つのミックスへ合流するまで

詳細表示（Advanced）の見本。主な端末はiPhone。画面内は英語のみで、語は現行コードの表示語（Live TX Pipeline、TX Bus、Peer Buses、Mix Down、RX Master、Connect、Participantsなど）に合わせ、説明は現行の注記程度に留める。定義の正本は 診断と詳細画面の構成。数値は説明用の例。

状態の語と記号・色・寸法・部品（状態ドット列・段の行・合流する木）は デザインシステム見本 を参照する。ここでは詳細表示（Advanced）の画面の組み合わせだけを示す。

診断（Diagnostics）

例: グループ通話中。Harukaは近距離で直接、KentaはHaruka経由の中継で低帯域のOpus、MikaはインターネットでPCMへフォールバック、Yuは未接続。相手ごとに送信条件と自分側の設定がばらばらな状態。

停止の例

使用中のAirPodsが切断された場合。最初に止まった段だけを赤で示し、下流は Idle として薄くする。下流の0を故障に見せない。

通話・ユーザー・グループ（Advanced）

タブは一般向けと同じく通話をタブにせず、Users（最初）・Groups・Diagnostics・Settings の4つにする。Users・Groups で選ぶとすぐ接続して通話のシート（Call）を開く（操作の流れ見本）。中身は詳細表示のまま。通話は相手が1人でも内部ではグループ（kind: direct）なので、Call では常にグループの実体（種類・ID・自分を含むメンバー）として見せる。

設定（Advanced）

リセットまでのスクロール全体。セクション名・項目名は現行コードの語のまま、並びを「アプリと自分 → 通話 → 接続 → 音声（信号の流れの順）→ リセット」のまとまりに整理する。左の色は右の構成図のグループに対応する。

構成（グループ ＞ セクション ＞ 項目）

アプリと自分
  1. App Layout Standard / Advanced
  2. Account Signed in with Apple · Sign Out · Delete Account
  3. Access Access Status · Restore Purchases · View Purchases
  4. Your Display Name Your name · Save Name
通話
  1. Automatic Disconnection Regular Calls · Calls Started from Watch
  2. Call Notifications Receive Call Requests（isEnabled）と CallNotifications の値をそのまま
  3. Call status display Show call status outside the app（macOSはmenu bar）

  1. Communication Local Network · Internet
  2. Internet Connection 状態 · Configure Internet Connection（sheet）
音声（信号の流れの順）
  1. Audio Session Mode · Use Speaker · Echo Cancellation · Duck Other Audio
  2. Audio I/O Input · Output · Transmit Voice Isolation Effect
  3. Voice Activity VAD Sensitivity
  4. Transmit Codec Codec · Sample Rate · AAC-ELD Bitrate／Opus Bitrate
  5. Audio Check Call · Audio Check · Recording Input · Playback Output · Record 5s and Play
リセット
  1. Reset Settings Reset All Settings（確認付き）

現行の順（App Layout → Account → Access → Call Notifications → Your Display Name → Call status display → Automatic Disconnection → Communication → Internet Connection → Audio Session → Audio I/O → Audio Check → Transmit Codec → Voice Activity → Reset Settings）から、同じ目的のセクションを隣り合わせ、音声は Session → I/O → VAD → Codec の信号順にそろえる。
