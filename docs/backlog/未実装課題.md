# 未実装課題

実装する必要がある残作業。現在の動作は[仕様](../spec/アーキテクチャ.md)、実装後の確認待ちは[未確認事項](../validation/未確認事項.md)を参照する。

| 課題 | 現状との差・対象 | 完了条件・制約 |
|---|---|---|
| 公開identity・端末資格管理 | Workerの個別端末registryは招待制試用向け（約4.5KiBまで）。公開登録・自動発行・失効を行うidentity backendがない | SFU transportとgroup招待形式を維持して入口認証を拡張する。本人確認・資格発行・失効を公開運用できること |
| 公開時のabuse・請求監視・停止運用 | SDP制限と参加者秒予約だけでは改変クライアントの過剰送信を金額で遮断できない | edge rate limit、実egress計測、請求通知、障害時停止運用を整備する。実運用の効果は検証側で確認する |

RTC診断とTURN資格lifecycleはこの一覧の実装作業ではない。現在の契約は[RTC](../spec/packages/RTC.md)・[Worker](../spec/server/Worker.md)、実サービス受け入れは検証側が所有する。
