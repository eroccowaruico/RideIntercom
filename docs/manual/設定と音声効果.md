# 設定と音声効果

## 設定の読み方

「設定した値」は希望値であり、OS・device・codecが実際に採用した値と一致するとは限らない。Diagnosticsのreportで適用・無視・失敗・fallbackを区別する。保存はApp再起動後も保持する意味であり、通話を切った直後のruntime値とは区別する。

## 接続と音声セッション

| 画面の項目 | 既定 / 選択肢 | 効果と注意点 | 反映 / 再起動後 |
|---|---|---|---|
| Local Network / Internet | 両方ON、最低1つON | 自端末が使う経路。Internet OFFでも近くの参加者による中継は可能 | 変更時は切断し再接続が必要 / 保存 |
| Configure Internet Connection | 未設定 | Worker HTTPS originと個別端末資格を入力。group招待ではなくサービス利用の資格 | 保存成功時は切断、失敗時は既存設定・通話を維持 / Keychain保存 |
| Mode: Burst mode | 既定、default session | インカム向けのdefault session。Echo Cancellationを明示的に要求できる。名称は送信のTCP/UDPや押して話す方式を意味しない | sessionへ適用 / 保存 |
| Mode: Stream mode | voiceChat session | 会話向けのOSルーティングを要求。音楽・機器への実際の影響はOS reportで確認 | sessionへ適用 / 保存 |
| Use Speaker | OFF（Auto） | speaker出力を希望。機器とOSにより実効出力が決まる。Echo Cancellationの組合せもresolved reportを確認 | 稼働中は必要に応じ入出力を再構成 / 保存しない |
| Echo Cancellation | BurstでON | マイクへ回り込む再生音の抑制をOSへ要求。Streamでは非表示、Use Speaker時は操作不可 | sessionへ適用 / profileの一部として保存 |
| Duck Other Audio | ON | 希望ONに加え、聞こえる受信音声がある間に他音声のダッキングを要求。常時音楽を下げる設定ではない | 動的反映 / 保存しない |
| Input / Output | Auto | 利用可能な機器が複数の場合に選択。希望と実デバイスをDiagnosticsで区別 | 稼働中は再構成。失敗・機器消失でAudio Paused / 保存しない |

## 音量・mute・エフェクト

| 操作場所と項目 | 既定 / 範囲 | 誰の何を変えるか | 反映 / 再起動後 |
|---|---|---|---|
| Call: Input Mute | OFF | 自分の声を送らない。受信・中継は独立 | 即時 / 保存しない |
| Call: Output Mute | OFF | 自分が聞く全員の音を止める。自分の声は引き続き送れる | 即時 / 保存しない |
| Call: Output Volume | 100%、0〜200% | 全員を混合した自分の出力。100%超は増幅し、その後のLimiterでピークを抑制 | 即時 / 保存しない |
| Call: 参加者Output | 100%、0〜100% | その話者だけを減衰。中継端末ではなく元の話者IDに対応 | 即時 / 保存しない |
| Settings: Transmit Voice Isolation Effect | ON、対応環境のみ表示 | 自分から送る音を処理。風切音などへの聴感効果は実機未確認 | 同じeffect nodeのbypassを更新 / 保存しない |
| Call: 参加者Voice Isolation | OFF、対応環境のみ表示 | その話者を自分で聞くときだけ処理 | 同じnodeのbypassを更新 / 保存しない |
| Call: Output Voice Isolation | OFF、対応環境のみ表示 | 混合後の自分の受信全体を処理。参加者別と両方ONなら二段になる | 同じnodeのbypassを更新 / 保存しない |

個別音量とマスター音量は掛け合わされる。例として個別50%・マスター50%なら、エフェクト適用前後の非線形な変化を除いたgainは25%。各Voice Isolationは適用対象が異なるため、困っている声の場所で調整する。音量0やDeleteは相手の参加資格を失効させる操作ではない。

### 画面に調整つまみを出していない処理

| 処理 | 現在の配置 | 役割 |
|---|---|---|
| VADGate | TX Mixerより前 | 声の検出と送信判定。無音の音声送信を抑制し、preroll / keepaliveはAudioTransmissionControllerが扱う |
| SoundIsolation | TX、RX peer、RX master | 各busで独立node。UIで有効・無効を切替 |
| DynamicsProcessor | TXのIsolation後 | 送信のダイナミクス処理。package既定parameterを採用し、App UIへ数値つまみを公開しない |
| TX PeakLimiter | Dynamics後 | 送信のピークを抑える |
| RX PeakLimiter | master gain後のrx-output | 全員の混合と増幅の後にピークを抑える |

中継は符号化済みpayloadの転送であり、中継者のエフェクト・mute・個別音量を他人の声へ重ねない。詳細は[音声処理仕様](../spec/App/音声処理仕様.md)と[packageの責務](../spec/packages/Overview.md)を参照する。

## VAD・codec・サンプルレート

| 項目 | 既定 / 候補 | 変化の意味 | 反映 / 保存 |
|---|---|---|---|
| VAD Sensitivity | Standard / Low Noise / Noisy | Low Noiseは小さなthreshold offset・短いattack。Noisyは大きなoffset・長いattackで発話判定を厳しくする。声の頭が欠ける／雑音で開く場合は比較して調整 | 判定状態をresetして即時 / 保存 |
| Codec | AAC-ELD v2 / PCM 16-bit / Opus | 自分から送る符号化方式。利用不可ならPCM fallback。相手の送信codecを変更しない | 稼働中は音声pipelineを再構築 / 保存 |
| RTC Audio | 48kHz / 24kHz / 16kHz、mono | 通信する音声format。hardwareの実sample rateとは別で、Mixer境界で明示変換 | 稼働中は音声pipelineを再構築 / 保存 |
| AAC-ELD v2 Bitrate | 32kbps、12〜128kbps、4kbps刻み | 要求する符号化bitrate。通信全体のbitrateではなく、packetや中継の上乗せがある | pipeline再構築 / 保存 |
| Opus Bitrate | 32kbps、6〜128kbps、2kbps刻み | Opus選択時だけ表示。実選択とfallbackはDiagnosticsで確認 | pipeline再構築 / 保存 |

サンプルレートやbitrateを下げれば必ず良いという設定ではない。声の情報量、fallback、wire overhead、話している割合を含めて比較する。費用の条件と計算は[Cost](../spec/server/Cost.md)を正とし、画面の32kbpsをそのまま課金容量に使わない。

## Audio Checkとリセット

| 操作 | 効果 / 変わらないもの |
|---|---|
| Record 5s and Play | 通話未接続時に自己録音・再生。通話中の全処理や相手への配送を証明しない |
| Stop Audio Check | 録音・再生を終了して再実行可能にする。通話開始時も旧Checkを終了 |
| Reset All Settings | session、device、VAD、codec、RTC format、bitrate、経路、音量、effect、出力muteを既定へ戻す |
| リセットで保持するもの | 保存group・参加者・group secret、local identity、Internet資格、入力mute。route設定が既定へ変わる場合は通話切断を伴う |

技術的な型・既定値・永続化の正本は[App設定値](../spec/App/Configuration/設定値一覧.md)、Appがpackageへ導出する値は[Configuration Bindings](../spec/App/Configuration/Bindings/RTC.md)以下。package自身の仕様とは分けて管理する。
