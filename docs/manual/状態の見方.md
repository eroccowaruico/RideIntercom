# 通話・音声・接続状態の見方

## 目的

本書は、RideIntercom App の画面上でユーザーが確認できる状態と、その読み方だけを定義する。

本書では画面に表示される状態のみを扱う。

## 対象画面

| 画面 | 確認すること |
|---|---|
| Call | 通話先、接続状態、音声入出力、参加者状態、招待可否 |
| Diagnostics | 通話、package runtime report、送受信、codec、再生、認証、経路の要約状態 |
| Settings | 入出力デバイス、音声設定、Audio Check の状態 |

画面項目の詳細な配置、ラベル、表示条件は `docs/spec/App/UI/画面項目定義.md` から参照する画面別文書を正とする。

## 音声経路による違い

DiagnosticsのAudio Pathを先に確認する。PCM meter・effect chain・peer音量・TX/RX pipelineはLocal / Internet共通のpacket audioを対象とする。未提供のRTT/lossは正常値として扱わない。Internet Serviceのチェックは設定と認証だけを確認し、実媒体の成功を示さない。

## Call 画面で確認する状態

| 表示 | 読み方 |
|---|---|
| グループ名 | 現在表示している通話対象グループ |
| 接続状態 | 未接続、接続準備中、接続済み、通話可能、再接続中、失敗を確認する |
| 経路表示 | Local / Internet / Offline など、現在使っている、または試行している経路 |
| Connect / Disconnect | 接続開始できる状態か、既に接続中で切断操作になる状態かを確認する |
| Invite | 招待 URL を共有できる状態かを確認する |
| 入力状態 | 自分のマイクが Unmuted か Muted かを確認する |
| 入力メーター | 自分の声がアプリへ入っているかを確認する |
| 出力状態 | 受信音声のマスター音量と出力ミュートを確認する |
| 他音声ダック状態 | 設定 ON と実際の発動中を区別して確認する |
| 参加者カード | 相手ごとの接続、認証、入力レベル、出力音量を確認する |
| エラー表示 | マイク権限、音声起動、入出力デバイス変更などの失敗理由を確認する |

## Diagnostics 画面で確認する状態

Diagnostics は、通常画面だけでは分かりにくい状態を要約して確認するための画面とする。ログを読ませる画面ではなく、一覧カードで現在状態を把握する画面とする。

| 表示 | 読み方 |
|---|---|
| Live TX Pipeline | SessionManager session、input stream、AudioMixer TX bus、TX effect chain、Codec、RTC TX の順に送信経路を確認する |
| Live RX Pipeline | RTC RX、Decode、AudioMixer peer buses、mix down、RX master、master effect chain、SessionManager output の順に受信経路を確認する |
| TX Effect Chain | `AudioMixerSnapshot` の `tx-bus.effectChain` 由来の SoundIsolation、DynamicsProcessor、PeakLimiter（VADGateはMixer前段の別reportで、現在の画面に専用詳細行はない）の現在状態を確認する |
| RX Peer Buses | peer ごとの接続、認証、decode codec、RX / JIT / PLAY、level、volume、peer bus effect chain を確認する |
| RX Master / Mix Down | `AudioMixerSnapshot.routes` と `rx-master` から peer bus が master bus へ集約されること、master volume、mute、limiter を確認する |
| Network Quality | RTC `RouteMetrics` の RTT、jitter、packet loss を確認する。queue / drop は RX pipeline 側で確認する |
| Call | 接続状態、media 状態、選択 group を確認する |
| Invite | 招待済み、招待可能、招待情報なしを確認する |
| Remote Runtime Status | `RTCRuntimeStatusTransport` で受け取った通信相手の接続、route、media、codec、package report を必要に応じて確認する |

Diagnostics の値は画面上の状態確認用として扱う。

## Settings 画面で確認する状態

| 表示 | 読み方 |
|---|---|
| Communication | RTC へ渡す有効 route のユーザー希望を確認する。active / available route は Diagnostics を正とする |
| Audio Session | Mode、Use Speaker、Echo Cancellation、Duck Other Audio の組み合わせを確認する |
| 入力デバイス | どの入力を使う設定になっているかを確認する |
| 出力デバイス | どの出力を使う設定になっているかを確認する |
| Voice Isolation Effect | SoundIsolation effect の有効/無効を確認する |
| Transmit Codec | 送信 codec 希望と bitrate を確認する |
| Voice Activity | 発話判定の感度 preset を確認する |
| Audio Check | マイク録音とスピーカー再生の確認状態を確認する |
| Reset | App の画面設定を初期値へ戻す操作を確認する |

設定値の正本は `docs/spec/App/Configuration/設定値一覧.md` とする。

## Audio Check で確認する状態

| 状態 | 読み方 |
|---|---|
| recording | マイク入力を取得している |
| playing | 録音した音声を再生している |
| completed | 入力と出力の確認が完了した |
| failed | 権限、入力なし、再生失敗などにより確認できなかった |

Audio Check は通話中の品質評価ではなく、端末の入力と出力が使えるかを画面上で確認する機能とする。

## 状態確認時の考え方

| 状況 | 確認する画面 |
|---|---|
| 相手につながらない | Call の接続状態、Diagnostics の Connection / Authentication |
| 自分の声が届かない | Call の入力状態と入力メーター、Diagnostics の Live TX Pipeline |
| 相手の声が聞こえない | Call の参加者入力、出力状態、Diagnostics の Live RX Pipeline / Network Quality |
| 音が小さい | Call のマスター出力音量、参加者別出力音量 |
| マイクが使えない | Call のエラー表示、Settings の入力デバイス、Diagnostics の Live TX Pipeline、Audio Check |
| 招待できない | Call の Invite 表示、Diagnostics の Invite Summary |

本書では、画面で何を確認するかだけを扱う。

## Networkの読み方

DiagnosticsのNetworkで通信の実測値を確認できる。RTTは自分のICE接続までの往復時間で、相手の声が届くまでの遅延ではない。send queueは送信待ちbyte数。Event dropsは端末内で期限や上限を超えたイベントの数で、回線のpacket lossとは異なる。

Not availableは計測値が提供されない状態。SCTP/DataChannelの損失率を0%として扱わない。Not measuredは未取得、staleは15秒以上更新がない状態。Direct group path / Relayedは最後に確認した受信経路で、将来の到達性を保証しない。
