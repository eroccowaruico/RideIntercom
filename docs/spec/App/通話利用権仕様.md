# 通話利用権仕様

購入者を中心に作成・開始しつつ、仲間との再開を妨げないためのApp共通判定である。[StoreKit利用権](利用権仕様.md)と[配布利用権](配布環境の利用権仕様.md)を使う。購入証明の端末間検証、購入台帳、通話終了の分散合意は設けない。

## 適用と操作の境界

| 対象 | 現行の動作 |
|---|---|
| 公開商品未設定 | 生成したStoreKitAccessのcatalogが空なら商用条件を適用しない。現在の試用を維持し、購入済みへの偽装や24時間起算点の新規生成はしない。認証・保存・所属・費用の条件は通常どおり適用 |
| 設定済み | 通常groupの作成・保存ユーザーの追加・招待の発行には操作者本人の有効な権利が必要。24時間の猶予だけでは追加権限を与えない |
| 直接通話 | 保存した相手の内部group解決と相手宛て招待は、未購入者から購入者へ呼び出す準備として許可。保存相手の削除・アカウントの変更等の既存条件は維持 |
| 受け取った招待・終了 | 招待の受諾と自分の通話終了を購入条件で拒否しない。本人・宛先・招待内容・現在通話の確認は維持 |
| 接続準備 | canStartCallsはログイン・アカウント整理の条件のまま。本人確認と制御通信を開始でき、媒体許可を別判定にする |
| 自分の権利 | StoreAccessEvaluationのactiveを使用。期限がある場合はその期限未満、有効な配布権利の期限nilも扱う。UIだけの購入済みフラグは使わない |
| 復元・更新 | ViewModelがStoreKitのObservable状態を監視し、権利の変更時に待機中の通話も再判定する。古いログイン世代の観測を停止し、画面の表示やonChangeに依存しない |

公開catalogを有効にする際には、購入・復元・取得失敗からの再試行が利用できることを合わせて確認する。商品設定前に商用条件だけを有効にする運用はしない。

## 成立と24時間

| 状態 | 判定・時刻の扱い |
|---|---|
| 起算点なし・24時間超過 | 少なくとも一人の有効な権利と、本人確認済みの別の参加者を必要とする。双方の媒体準備が成立するまで音声を許可せず、起算点も保存しない |
| 未準備の購入者 | 購入者が接続しただけで未購入者同士の通話を成立させない。権利を持つ参加者も媒体準備できていることを使う |
| 新しい購入者ありの成立 | その時刻を保存・共有する。呼出し・無応答・音声初期化失敗では生成しない |
| 保存時刻から24時間以内 | 両者未購入でも再開可能。ちょうど86,400秒も含む。未購入者だけの再開では更新しない |
| 継続中 | 期限切れ・返金・24時間経過で切らない。購入者の途中参加や重複の制御情報でも起算点を更新しない |
| 最後の別ユーザーが消失 | 成立状態を解除し、再接続は同じ24時間条件を評価する。未確認peerや自分の別端末だけでは継続としない |
| 部分経路断・音声機器停止 | 既存の参加が維持される場合は成立を解除せず、復帰で新しい起算点を作らない |
| 不正・未来の時刻 | 新しい猶予の根拠にしない。小さい時計差で相手の権利・準備状態まで捨てず、起算点だけを個別に検証する。正当な新しい成立で、保存された未来の不正値から復旧できる |

一般画面の「通話中」と直近通話の記録にも同じ成立状態を使う。媒体だけ準備できた状態を通話成立と表示しない。

## 状態交換と音声許可

| 対象 | 現行の契約 |
|---|---|
| 制御形式 | rideintercom.call-access.v1で、group・受信member・既存challenge・revision・有効権利フラグ・任意期限・媒体準備・成立中か・任意起算点を送る。既存端末鍵の用途別署名を使用 |
| 受理 | 現在の認証peerとmembership、検証済み端末公開鍵、group、受信者、challenge、新しいrevisionを確認する。古い参加・改ざん署名・別宛先は拒否 |
| 信頼の範囲 | 正規アプリ同士の協調を前提とする状態交換。StoreKit取引本体は送らず、改変端末への厳密な課金強制とは扱わない |
| 媒体 | 既存RTCのmembership別音声許可へ商用条件を合成し、本人確認と通話成立前の音声を通さない。通話中の新参加者が準備できた際も許可を更新 |
| 送信頻度 | 値が変化した場合と、初回確認の応答だけ送る。同値を周期再送せず、新たなネットワーク購入照会は追加しない |
| tick | 既存の通話tickを制御接続中にも使用する。再試行中は維持し、終端失敗・明示切断で停止。音声初期化失敗を毎tick再試行しない |

## 保存と復旧

| 対象 | 動作 |
|---|---|
| GroupSnapshot | version 7でgroupごとの任意lastSponsoredStartを保持。通常編集・名前変更・再読込で維持し、group削除・明示reset・アカウント消去で除去 |
| 移行 | 旧形式を既存のatomic commitと読戻しで更新し、起算点がない場合に現在時刻を補わない。旧版は新しいschemaを拒否 |
| 書込失敗 | 成立済みの音声とメモリ内の起算点を維持し、保存の問題を表示する。同じ値を毎tick書き直さない。失敗した保存の永続性は保証せず、次の接続で保存済み・共有された値から再評価 |
| 分散状態 | 各端末の有効な最新時刻を統合する。古い値で新しい時刻を上書きせず、全員の合意やサーバー応答を保存・再開の前提にしない |

通知の用途別認可、ユーザー一覧へ保存する直接関係、利用枠はこの商用判定と独立する。groupで見えた相手を、この状態交換によって個別通話先や通知先へ昇格させない。
