# RideIntercom App ログ仕様

## 目的

本書は、現行のRideIntercom App が `docs/policies/ログ記録規約.md` をどう満たすかを定義する。

ログ基盤、レベル、禁止情報、共通 metadata は `docs/policies/ログ記録規約.md` を正とする。本書ではAppのevent名・metadataの設計契約と現行の発行状況を扱う。以下のevent表のmetadataは付与する値の候補であり、全呼出で全項目が付く保証ではない。末尾の実装差分を合わせて読む。

## Logger

| 領域 | Logger label | 主な入力 |
|---|---|---|
| App lifecycle | `com.yowamushi-inc.RideIntercom.app` | App 起動、scene、deep link |
| RTC | `com.yowamushi-inc.RideIntercom.rtc` | `RTC.CallSessionEvent`、route metrics |
| Audio | `com.yowamushi-inc.RideIntercom.audio` | `SessionManager` report/event、Codec fallback、Mixer 起動 |
| Security | `com.yowamushi-inc.RideIntercom.security` | Keychain、credential 生成、invite validation |
| Settings | `com.yowamushi-inc.RideIntercom.settings` | ユーザー設定変更、reset |

## 共通方針

| 項目 | 仕様 |
|---|---|
| 初期化 | App 起動時に `LoggingSystem.bootstrap` を一度だけ実行する |
| 本文 | 可変値を埋め込まず、安定した event 名を使う |
| metadata | 調査に必要な値だけを入れる |
| operationID | 接続開始、media 開始、Audio Check、invite 受理など複数ログにまたがる操作で発行する |
| 高頻度処理 | audio frame、packet、tick ごとの通常ログは出さない |
| 失敗時 | package の `failed` report は warning / error へ変換し、`ignored` は原則 debug または notice にする |

## 記録禁止

| 情報 | 方針 |
|---|---|
| group secret | 記録禁止 |
| invite token | 記録禁止 |
| 認証 MAC / 鍵材料 | 記録禁止 |
| 音声 sample / encoded payload | 記録禁止 |
| 復号済み application data payload | 原則禁止 |
| peer / group の生 ID | 原則禁止。ハッシュまたは短縮値を使う |

## Diagnostics との関係

| 項目 | 方針 |
|---|---|
| Diagnostics | 直近の package report / event と metrics を画面表示する |
| Logs | 操作境界、失敗、fallback、handover だけを記録する |
| 高頻度値 | Diagnostics では表示してよいが、通常ログへは出さない |
| 機密値 | Diagnostics と Logs のどちらにも出さない |

## 現行実装と設計契約の差分

| 状態 | event / metadata | 読み方 |
|---|---|---|
| 生IDの保護 | `Logger.Metadata.event`が`peerID` / `groupID`を除去しSHA-256の先頭12byte（24hex）の`peerIDHash` / `groupIDHash`へ変換 | 個別音量・Isolation操作の生peer ID出力を修正。安定した仮名であり完全な匿名性を保証しない |
| 現行で追加発行 | `audio.pipeline.capture_failed` / `audio.pipeline.rebuild_failed` / `audio.pipeline.receive_failed` | pipeline単位の失敗。下位codecの個別イベント名と同一ではない |
| 現行で追加発行 | `settings.rtc_audio_format.changed` | presetとsampleRateを記録 |
| 設計上の候補・未発行 | `app.deeplink.invite.accepted` / `app.deeplink.invite.rejected` / `app.permission.microphone.denied` | UIの成功・失敗処理はあるが、このevent名の構造化ログを実装済みとは扱わない |
| 設計上の候補・未発行 | `audio.codec.decode_failed` / `rtc.application_data.decode_failed` / `rtc.handshake.rejected` | 現在のreport・error経路と、この名前での発行を区別 |
| 任意metadata | `operationID`等 | 全操作への付与は未統一。event表を実際の収集済みfield一覧として使わない |

実装は[RideIntercomLogging](../../../RideIntercom/App/RideIntercomLogging.swift)と各ViewModelの`.event(...)`呼出、回帰は[LoggingPrivacyTests](../../../RideIntercomTests/LoggingPrivacyTests.swift)を参照する。
