# RideIntercom App ログ仕様

本書は現在発行するeventとmetadataを記述する。共通の目的・禁止事項は[ログ記録規約](../../policies/ログ記録規約.md)、追加案は[改善候補](../../backlog/改善候補.md)へ分ける。

## 基盤と値の扱い

| 項目 | 現在の動作 |
|---|---|
| 初期化 | App起動時にLoggingSystem.bootstrapを1回実行。lockとdidBootstrapで反復を防ぐ |
| 出力 | StreamLogHandler.standardOutput。Debugはdebug以上、Releaseはinfo以上 |
| Logger | com.yowamushi-inc.RideIntercomのapp / rtc / audio / security / settingsを定義。securityの現在の発行箇所はない |
| event | 固定文字列を本文とmetadataのeventへ設定 |
| 生ID | Logger.Metadata.eventがpeerID / groupIDを取り除き、SHA-256先頭12byte（24hex）のpeerIDHash / groupIDHashへ変換。安定した仮名であり完全匿名ではない |
| operationID | 現在はapp.lifecycle.startedとsettings.resetで付与。他eventには自動付与しない |
| 高頻度値 | 通常のフレーム・packet・tickは逐次ログにしない。Diagnosticsはpackage report / event / metricsを表示する |
| 機密値 | group secret、招待token、鍵、認証MAC、音声・復号payloadをmetadataへ渡さない |

## 発行イベント

各行はソースの発行箇所で渡すmetadataの集合。複数箇所で差があるfieldは任意と明記する。全行にeventが追加される。失敗条件やDebug/Releaseのレベルによって、全実行で出力されるとは限らない。

| Event | Level | metadata（event以外） |
|---|---|---|
| `app.lifecycle.started` | `.info` | `operationID` |
| `audio.codec.fallback` | `.notice` | `reason`, `requestedCodec`, `selectedCodec` |
| `audio.input.voice_processing_failed` | `.warning` | `errorType`, `isRecoverable` |
| `audio.input.voice_processing_ignored` | `.debug` | `reason` |
| `audio.media.started` | `.info` | `codec`, `route` |
| `audio.media.stopped` | `.info` | `route` |
| `audio.output.schedule_failed` | `.warning` | `errorType`, `isRecoverable` |
| `audio.pipeline.capture_failed` | `.warning` | `errorType`, `isRecoverable` |
| `audio.pipeline.rebuild_failed` | `.warning` | `errorType`, `isRecoverable` |
| `audio.pipeline.receive_failed` | `.warning` | `errorType`, `isRecoverable` |
| `audio.session.route_changed` | `.notice` | なし |
| `audio.session.failed` | `.error` | `isRecoverable`, `operation`。任意: `errorType` |
| `rtc.connection.failed` | `.error` | `isRecoverable`, `route` |
| `rtc.connection.started` | `.info` | `peerCount`, `route` |
| `rtc.route.degraded` | `.warning` | `drop`, `packetLoss`, `route` |
| `settings.audio_device.changed` | `.info` | `direction`, `selection` |
| `settings.audio_session.changed` | `.info` | `profile`。任意: `speaker` |
| `settings.audio_speaker.changed` | `.info` | `enabled`, `profile` |
| `settings.codec.bitrate_changed` | `.info` | `bitRate`, `codec` |
| `settings.codec.changed` | `.info` | `codec`, `selectedCodec` |
| `settings.ducking.changed` | `.info` | `enabled` |
| `settings.echo_cancellation.changed` | `.info` | `enabled`, `speaker` |
| `settings.receive_master_sound_isolation.changed` | `.info` | `enabled` |
| `settings.remote_output_volume.changed` | `.info` | `peerIDHash`, `volume` |
| `settings.remote_sound_isolation.changed` | `.info` | `enabled`, `peerIDHash` |
| `settings.reset` | `.notice` | `operationID` |
| `settings.rtc_audio_format.changed` | `.info` | `preset`, `sampleRate` |
| `settings.rtc_routes.changed` | `.info` | `enabledRoutes` |
| `settings.sound_isolation.changed` | `.info` | `enabled` |
| `settings.vad.changed` | `.info` | `preset` |

## 対応する実装

[RideIntercomLogging](../../../RideIntercom/App/RideIntercomLogging.swift)、[App起動](../../../RideIntercom/App/RideIntercomApp.swift)、[ViewModel](../../../RideIntercom/Intercom/ViewModel)のAppLoggers呼出を正本として更新する。pipelineのcapture / rebuild / receive失敗はpipeline単位のeventであり、codecやhandshakeの個別失敗eventとは別である。経路の維持状態はRTC runtime statusを用いる。
