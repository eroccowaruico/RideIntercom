# RideCom UI アイコン適用

## 目的

本書は `docs/design/アイコン定義.md` を RideCom App の UI 項目へ適用する正本である。

## 正式アプリアイコン

| 対象 | 現行仕様 |
|---|---|
| 図案・設定の正本 | `RideIntercom/RideComAppIcon.icon`。`Background.svg`・`Road-Invert.svg`・`Bubble-Left.svg`・`Bubble-Right.svg`とIcon Composer設定（`icon.json`）を一つのpackageに保持する |
| 層と配置 | 上から`Bubble-Left`・`Bubble-Right`（Glass、塗りはIcon Composerの単色）、`Road-Invert`（白い面。抜いた部分が道の車線になる。ライトはsystem-light、ダークは濃紺）、`Background`（青の単色、自動グラデーション）。元のSVGとは位置と大きさが異なり、`icon.json`の`position-specializations`で調整している（`Road-Invert`は1.16倍・(97, 98)pt移動、`Background`は1.66倍、吹き出しは原寸）。SVGを直接描くと配置がずれるため、アイコンの画像はIcon Composerまたは`ictool`の書き出しを正とする |
| 図形の重なり | 同色の全pathを一つのSVG layerへまとめる。制作上の部品ごとにはガラス効果を掛けない |
| 外観 | 標準・ダーク・クリア・色付きの描画と照明・マスクはIcon ComposerとOSへ委ね、光沢・影・角丸を元SVGへ焼き込まない |
| Watch | Watch targetのResources phaseからApp targetと同じ`.icon` resourceを参照する。アイコンpackageは一つだけを管理する。円形マスクで欠けないよう、watchOSだけ`icon.json`で吹き出しを0.95倍にして移動（左(13, −16)pt、右(−6.2, −7)pt）、`Road-Invert`を(44.4, 75.6)pt移動、`Background`を1.5倍にする |
| 配布形式 | Icon Composer packageからXcode Asset Compilerがplatform別のアイコンvariantを生成する。アプリアイコン用の重複PNG catalogは持たない |
| アイコンの画像 | アイコンをそのまま表示できる場所は、`ictool`でiOSの`Default`（ライト）と`Dark`（ダーク）を表示の大きさの@1x・@2x・@3xに書き出した画像を使う。サインイン・必須アップデートは112ptの`RideIntercom/Shared/Appearance.xcassets/ridecom.appicon.imageset`、Widget・ライブアクティビティ・Dynamic Islandは22ptの`ridecom.appicon.small.imageset`。縮小・拡大で流用せず、大きさごとに書き出す。`.icon`を変えたら同じ手順で書き出し直す（[開発環境](../../../development/開発環境.md#配布用アプリアイコン)） |
| 画像を置けない場所の識別記号 | Macメニューバー（テンプレート描画）とControlは`ridecom.glyph`（`Appearance.xcassets/ridecom.glyph.symbolset`）。`.icon`の`Road-Invert`と吹き出しを同じ配置で重ね、アイコンの正方形から白い面を除いた道とシュプールを第1層、吹き出し2つをガラスの輪郭にした第2層にしたカスタムシンボル（[カスタムシンボル](../../../design/アイコン定義.md#カスタムシンボル)） |

生成・再確認の入口は[開発環境](../../../development/開発環境.md#配布用アプリアイコン)。画面内の操作・状態を表すSF Symbolsは以下の意味別定義に従う。

## Tabs / Users / Groups

| 項目ID | 項目 | 仕様アイコン | 補足 |
|---|---|---|---|
| `closeCallButton` / `callAccessoryMuteButton` | 通話を閉じる／アクセサリのミュート | `chevron.down` / `mic.slash` | 通話はタブにせず、シート・右の列とアクセサリで扱う |
| `usersTab` / `groupsTab` | ユーザー / グループ | `person.2` / `person.3` | 一覧への復帰・選択導線 |
| `diagnosticsTab` | 診断タブ | `gauge` | 計測・観測入口 |
| `settingsTab` | 設定タブ | `gearshape` | 設定入口 |
| `standardGroup-{UUID}` | グループ行先頭 | `person.3.fill` | 緑の円内に白い記号。行を選ぶとCallへ移動 |
| `standardUser-{UUID}` / 参加者 | 人物 | `person.fill` | 青い円内に白い記号。文字サイズに追従し、User / Groupを読み上げる。編集可能な画像ではない |
| Standard Call見出し | 選択中の相手・グループ | `person.fill` / `person.3.fill` | 一覧と同じ種別・配色の大きい固定記号を中央配置 |
| `standardCreateGroupButton` | グループ作成 | `plus` | Groupsで新規作成 |
| `callMoreMenu` | 通話の…メニュー | `ellipsis` | グループの設定・相手の設定、メンバーの追加、招待 |
| `User Settings` / `Group Settings` | 行の長押し・swipeの設定 | `gearshape` | 行末の`info.circle`・鉛筆は置かない |
| なし | グループ削除 | `trash` | swipe / context menu の破壊操作 |
