# RideIntercom 画面項目定義

## 目的

本書は現行のRideIntercom AppのUI項目定義の入口である。

画面ごとの項目はファイルを分け、1 ファイルが肥大化しないようにする。各画面の正本は下表の文書とする。

## 画面別定義

| 対象 | 正本 | 役割 |
|---|---|---|
| 共通構成 | `docs/spec/App/UI/共通項目.md` | `TabView`、共通ナビゲーション、共通表示方針 |
| Call / Users / Groups | `docs/spec/App/UI/Call.md` | Standardの個人・グループの選択と通話、Advancedのグループ選択、共通の参加者・入出力操作 |
| Diagnostics | `docs/spec/App/UI/Diagnostics.md` | AdvancedのLive pipeline と現在状態の一覧カード |
| Settings | `docs/spec/App/UI/Settings.md` | アカウント・利用権・画面切替、Communication、Audio Session、Audio I/O、Audio Check、codec、VAD、reset |
| アイコン | `docs/spec/App/UI/アイコン適用.md` | design system の SF Symbol 適用先 |

## 記載方針

| 項目 | 方針 |
|---|---|
| 対象画面 | Standardは`Call`、`Users`、`Groups`、`Settings`。Advancedは`Call`、`Diagnostics`、`Settings` |
| 表先頭列 | UI項目を定義する表は、先頭列を `項目名（日本語）` に統一する |
| 親子関係 | 画面、セクション、子項目を分けて所属関係を追えるようにする |
| データ仕様 | 値の型、値域、参照元、表示用整形方法を記載する |
| 表示仕様 | 見え方、レイアウト、色、操作方法、補助表示の意味を記載する |
| 状態 | 接続状態、音声状態、診断状態など、画面から読み取るべき状態変化を記載する |
| 異常系 | 継続可能な `ignored` / fallback と、操作失敗の `failed` を分ける |

## 品質点検で追加した確認項目

| 画面 | 項目 | ID | 提供条件 |
|---|---|---|---|
| Diagnostics | Audio Path | `audioPathSummary` | 常時。Local / Internet共通のpacket audio責務を表示 |
| Diagnostics | Internet Service | `internetServiceCheckStatus` | 常時。認証確認と媒体未検証を分ける |
| Diagnostics | Check Internet Service | `checkInternetService` | 資格保存済み・確認処理なしで有効 |
| Settings | Internet保存状態 | `internetConfigurationStatus` | 資格の有無だけ表示 |
| Settings | AppleによるInternet登録 | `prepareInternetAppleSignIn` / `internetAppleSignInButton` / `internetAppleSignInStatus` | Internet設定sheet。準備後に認証可能。現在のAppleアカウントと一致する場合だけ保存。登録頻度制限の待機・再試行と、8端末の上限からの復帰をstatusで案内 |
| Settings | Stop Audio Check | `stopAudioCheckButton` | 録音・再生中 |

混在通話・機器停止時の操作範囲と表示は [Call](Call.md) / [Settings](Settings.md) / [Diagnostics](Diagnostics.md) の経路別表を優先する。

| 混在通話の追加項目 | identifier | 表示条件と動作 |
|---|---|---|
| Internet再試行案内 | `connectivityNotice` | active groupでInternet単独失敗。到達可能な相手との接続維持を説明 |
| 機器停止理由 | `audioRouteNotice` | active groupで機器消失・音声再起動失敗 |
| 音声再開 | `resumeAudioButton` | 機器停止待ち。認証peerがいるとき再試行可能 |

## 表示名の設定と復元

| 画面 | 項目ID | 内容 |
|---|---|---|
| Settings | `localDisplayNameField` / `saveLocalDisplayNameButton` / `localDisplayNameSaved` | 本人名の入力・保存・成功表示 |
| Saved Users編集 | `savedUserOriginalName` / `resetUserNameButton` | 本人名の確認・端末内呼び名の解除 |
| 参加者名編集 | `groupMemberNameField` / `groupMemberOriginalName` / `saveGroupMemberNameButton` / `resetGroupMemberNameButton` | group内の呼び名入力・本人名表示・保存・復元。通常groupの同本人の代表端末交換でも呼び名を保持する |
