# RideIntercom 画面・状態遷移

## 目的

本書は、現行のRideIntercom App の画面遷移と主要状態遷移を定義する。

RTC、SessionManager、Codec、Mixer の内部状態は各 package 仕様を正とし、本書では App が UI 表示へ要約する状態だけを扱う。

## 画面遷移

```mermaid
flowchart LR
    A[App起動] --> B[TabView]
    B --> C[Call]
    B --> D[Diagnostics]
    B --> E[Settings]

    C --> F{selectedGroup}
    F -- none --> G[Groups画面]
    F -- selected --> H[Call画面]

    G -- Create / Select --> H
    H -- Groups / 接続維持 --> G
    H -- Invite URL受理成功 --> H
```

## Call 操作遷移

```mermaid
flowchart TD
    A[Group Selected] --> X{別groupが接続中か}
    X -->|いいえ: 選択で接続| C[RTC prepare]
    X -->|はい: 閲覧だけ| B[Prepared]
    B -->|Connect: 旧通話停止| C[RTC prepare]
    C --> D[RTC startConnection]
    D -->|connected/authenticated| E[RTC startMedia]
    E --> F[App audio pipeline start]
    F --> G[Talking]
    G -->|Disconnect| H[App audio pipeline stop]
    H --> I[RTC stopMedia/stopConnection]
    I --> B
```

| 状態 | UI 表示 | package 対応 |
|---|---|---|
| Prepared | 選択 group、Connect 可能 | RTC request を組み立て可能 |
| Connecting | 接続準備中 | `CallSession.startConnection` 実行中 |
| Connected / Control Only | control plane 成立、media 未開始 | RTC connection 成立、media 未開始 |
| Starting Media | 音声開始中 | RTC `startMedia` と App audio pipeline start |
| Talking | 通話可能 | RTC media と App audio pipeline running |
| Reconnecting | 復旧中 | RouteManagerの到達経路再試行。残る経路は維持 |
| Failed | 再試行可能な失敗 | RTC / SessionManager / Codec の failed report |

## Audio pipeline 状態

```mermaid
stateDiagram-v2
    [*] --> idle
    idle --> configuringSession: media start
    configuringSession --> startingInput: session report applied or ignored
    startingInput --> startingOutput: input stream started
    startingOutput --> running: output renderer started
    running --> updatingVoiceProcessing: mute / ducking change
    running --> running: SoundIsolation node bypass更新
    updatingVoiceProcessing --> running: report applied or ignored
    running --> stopping: media stop
    stopping --> idle: owned streams stopped
    configuringSession --> failed: failed report
    startingInput --> failed: failed report
    startingOutput --> failed: failed report
    failed --> idle: dismiss / retry reset
```

| 状態 | App の扱い |
|---|---|
| `configuringSession` | `AudioSessionManager.configure(_:)` と `setActive(true)` の report を保持する |
| `startingInput` | `AudioInputStreamCapture.start()` の report を保持する |
| `updatingVoiceProcessing` | `AudioInputStreamCapture.updateVoiceProcessing(_:)` を呼び、入力 stream は止めない |
| `startingOutput` | `AudioOutputStreamRenderer.start()` の report を保持する |
| `failed` | Call の音声エラーと Diagnostics に表示し、ログへ記録する |

## Codec 状態

```mermaid
stateDiagram-v2
    [*] --> requested
    requested --> selected: requested codec available
    requested --> fallback: requested codec unavailable or route unsupported
    fallback --> selected: pcm16 available
    selected --> failed: encode/decode unrecoverable failure
    failed --> requested: user changes codec or reconnects
```

| 状態 | UI 表示 |
|---|---|
| requested | Settings の選択値 |
| selected | Diagnostics の Codec 行 |
| fallback | requested と selected を分け、理由を表示 |
| failed | codec error として Diagnostics とログに残す |

## AudioCheckPhase

```mermaid
stateDiagram-v2
    [*] --> idle
    idle --> recording: startAudioCheck
    recording --> failed: setup失敗 / samples empty
    recording --> playing: 5秒録音完了
    playing --> completed: 5秒再生完了
    recording --> idle: Stop / Connect / 機器変更
    playing --> idle: Stop / Connect / 機器変更
    playing --> failed: 再生起動失敗
    failed --> recording: retry
    completed --> recording: retry
```

## 補助状態

| 状態 | 遷移概要 |
|---|---|
| `selectedGroup` | `nil` なら Groups 画面、非 `nil` なら Call 画面 |
| `activeGroupID` | RTC 接続中または接続準備中の group ID |
| `audioCheckOwnsAudioPipeline` | 通話未開始時に Audio Check が一時的に audio pipeline を所有し、完了/失敗時に解放 |
| `isOtherAudioDuckingActive` | Duck Other Audio 設定 ON かつ可聴な受信音声が最終出力へ渡っている間だけ `true` |
| `selectedCodec` | `preferredTransmitCodec`、`CodecRuntimeReport`、route capability から決まる実 codec |

## 復旧時に固定した遷移

| 起点 | 操作 / イベント | 到達状態 |
|---|---|---|
| A通話中 | Bを選択 | B閲覧、A通話継続 |
| B閲覧、A通話中 | Connect | A停止・旧通知無効化、B接続開始 |
| Audio Check recording / playing | 通話media開始 | Checkをidleへ戻し所有資源を停止後、通話開始 |
| media開始途中 | input / output / Mixer失敗 | 音声資源解放、error表示、再試行可能 |
| 切断後 | 旧timer / 旧通知 | 現在の状態へ反映しない |

Diagnosticsのgraphとeffect chainは実Mixerだけを表示する。未開始なら空、未接続effectは稼働中と表示しない。

## 機器と混在経路の遷移

```mermaid
stateDiagram-v2
    Talking --> AudioPaused: 使用中の機器消失
    AudioPaused --> AudioPaused: presence / 認証更新 / 再開失敗
    AudioPaused --> Talking: Resume Audio成功
    Talking --> Talking: 一部route失敗 / peer離脱、他peer到達可能
    Talking --> Reconnecting: 到達peerなし
    Reconnecting --> Talking: 経路復帰・認証、機器停止待ちなし
    AudioPaused --> Idle: Disconnect
```

AudioPausedでもRTC接続と他者の中継は続く。再開時も入力muteと出力muteの意図を保持する。Audio Check中の機器消失はCheckをidleへ戻し、古い完了callbackを破棄する。
