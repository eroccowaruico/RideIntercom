## Git・ビルド設定の整理

| 変更 | 確認 |
|---|---|
| 9 packageの相対パスとproduct所属を明示、重複productリンクを除去 | macOS/iOS Simulator両方のbuild成功 (`config-macos.log`, `config-ios.log`) |
| Apple frameworkをSDKROOT基準に変更 | 固定iPhoneOS26.4 SDK参照なし |
| Appの同期フォルダからpackages全体を除外 | packageとしてのみコンパイル。AudioCoreの資源コピーを除去 |
| 生成物・Worker秘密設定・個人Xcode設定をignore | ソース、lockfile、共有scheme、WebRTC管理バイナリは維持 |
| 追跡済みxcuserdataの解除 | ローカルファイルは保持 |

XcodeはAppIntentsを使用しないターゲットにも `Metadata extraction skipped, no AppIntents.framework dependency found` を出力する。ビルド成功とこのツール診断を区別し、警告ゼロとは記録しない。

## 再現コマンド

```bash
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
xcodebuild build -project RideIntercom.xcodeproj -scheme RideIntercom -destination 'platform=macOS,arch=arm64' -derivedDataPath /private/tmp/rideintercom-dev-validation/DerivedData
xcodebuild build -project RideIntercom.xcodeproj -scheme RideIntercom -destination 'generic/platform=iOS Simulator' -derivedDataPath /private/tmp/rideintercom-dev-validation/DerivedData-iOS
xcodebuild test -project RideIntercom.xcodeproj -scheme RideIntercom -destination 'platform=macOS,arch=arm64' -only-testing:RideIntercomTests -derivedDataPath /private/tmp/rideintercom-dev-validation/DerivedData
# 各Package.swiftの親ディレクトリを指定して9 packageすべて実行
swift test --package-path RideIntercom/packages/RTC
```
