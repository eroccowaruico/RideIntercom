# 未確認事項

実装の存在や自動試験の成功だけでは確定できない受け入れを管理する。アカウント・実機の準備後に確認し、条件と証跡をhistoryへ残す。未実装作業は[課題](../backlog/未実装課題.md)で管理する。

| 対象 | 確認する内容 | 現在の証拠との境界 |
|---|---|---|
| 実Cloudflare SFU | HTTP契約・所有者・quota・WS sender・expiry alarm、実媒体の双方向音声、peer入退室10回以上、再参加 | workerdのprovider代替試験・Swiftペア・native loopbackは実SFUの確認ではない |
| TURN・制限回線 | UDP制限/TCP/TLS回線、資格取得・失効反映時間、長時間の資格更新と同一接続継続 | HTTP契約・資格通知・native既存connectionへの設定更新の自動試験と区別する |
| 混在グループ | Mac/iPhoneの招待・双方向・一部離脱・中継交代、Local消失と復帰、Internet非利用者を含む通話 | 仮想4端末の自動試験は実無線・SFUの品質保証ではない |
| 音声と人数 | Audio Check録音再生、実時間10分・同時発話・ミュート・再接続、8人通話品質 | 合成30,000フレームとオフラインAVAudioEngineは実時間の音響評価ではない |
| 音声機器・OS | Bluetooth/有線の切断・切替と通知順、画面ロック中継続、再開操作、音楽との共存 | SessionManager runtime eventを入力する試験はOS実通知・実機聴感を保証しない |
| 共通音声調整 | Local/Internetのeffect・peer音量・master音量、codec別帯域・音質・消費電力 | 共通pipelineのPCM試験と実機評価を区別する |
| UI・アクセシビリティ | VoiceOver実操作、Mac/iPadサイズ別の最終表示・入力 | 専用Simulatorのlarge text/dark/landscape操作と区別する |
| 保存復旧・実OS中断 | OSによるプロセスkill、端末ロックとKeychainの実通知、電源断・媒体故障 | commit前後の故障注入と新repositoryによる再読込、Simulatorの破損→reset操作は自動化。電源断耐久性・履歴選択復元は提供しない |
| 非協調RTC | 長時間戻らないvendor処理の停止完了 | gateで待機件数・生成数・復帰後の順序は検証。強制終了や停止時刻の保証はなく、最大1件の実行中awaitが残り得る |
| Xcode / VS Code | 新規・隠しファイル・bundle内部、削除・移動後の追随、再起動後の表示。rootと既存folder配下へ一時ファイルを作り、Add Filesなしの表示を確認して削除。Xcode参照修復後のpackage読み込みエラー消失とproject種別の自己参照がないこと（folder種別の参照は許容） | 構造検査と参照修復後のmacOS buildは成功。画面操作権限がなく再起動後の確認は後続。条件は[検証状況](README.md)を参照 |
| ローカルgate運用 | mainへpushする前のローカル検証実行と証跡の保管 | CIの自動起動は費用制約で停止。GitHub上での強制gateはない |
| iOS配布 | iCloud署名・アイコン・WebRTC dSYM修復後の新ArchiveをApp Store Connectへ再送し、サーバー側検証の通過を確認 | ローカルのiOS Archive・App Store向けIPA書き出し・署名検証、120px/152pxアイコンと名前、WebRTC dSYM UUID一致を確認。再アップロードは未実行。条件は[検証状況](README.md)を参照 |
| 費用 | 実egress、WS頻度、DO duration、HTTP CPU、TURN追加処理・独立利用を測り試算へ反映 | 合成fixtureのbyte数は実請求ではない。RealtimeKit無料10,000分のアカウント適用条件・料金文書との整合も確認する |
| 公開規模の運用 | identity・abuse・請求監視・停止運用の実効性 | 実装課題の完了後に確認。参加者秒上限は金額の厳密な上限ではない |
