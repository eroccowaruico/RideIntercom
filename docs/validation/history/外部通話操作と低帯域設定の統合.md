# 外部通話操作と低帯域設定の統合

2026-10-31、`de94ebef`を基準にWidget・Control・Live Activity、iPhone連携Watch、AACの手動低帯域候補、iPhone/iPadのシート表示、OS権限と配布設定をApp工程で統合した。packageとserverの実装は変更していない。通知Appの追加とMac WebRTC artifactの修正は次工程へ分ける。

## 統合した境界

- 全入口で既存のAppCallOwner／ViewModel／通話参照を使う。保存相手・ログイン・利用権を実行時に再確認し、古い終了要求で新しい通話を止めない。Watchの状態もAppと同じ`callStatus(for:)`から作る。
- 特定Widgetへ共有するのは選択用ID・名前・種別だけ。秘密鍵・購入履歴・通知資格を共有せず、group内だけの相手を個別宛先にしない。OSの古い表示と、操作時の再認可を区別する。
- AACの48kHz／32kbps・24kHz／16kbpsは音質低下を明示する手動候補。既定・品質基準・Opus下限を維持する。[84条件の通信なし評価](低帯域codecの通信なし比較.md)と実通信・実機の聞き取りを分ける。
- Watchのアイコン、日英のOS権限説明、OS別のPush entitlement、共通APNs環境設定を追加し、不要な背景通知宣言を除いた。[設定の正本](../../development/OS権限と配布設定.md)で外部登録と区別する。

iPhone・iPadの日本語横画面で、keyboardとgroup作成sheetの保存画像も目視し、作成toolbarが画面内にあることを確認した。添付は上記各証跡の`screens/manifest.json`で対応付ける。Release生成後の変更はUIテストの探索helperだけであり、App・Widget・Watchの生成入力は最終試験と一致する。

統合証跡は`.validation/external-controls-delivery`へ集約した。App/設定/artifactと未変更のserverを含む入力照合、テスト件数、実サービス未受入を記録し、xcresultの元保存先も残した。

最初の統合buildは`End Call`と`End call`の翻訳symbol衝突で失敗し、既存keyへ統一した。テストのスクロール／switch位置の調整と、上記の実シート不具合を区別した。最初の採番phase移動時は旧DerivedDataのstale output warningを記録し、後続buildでは解消した。AppIntentsを持たないtest/Watch bundleのmetadata extraction skippedは工具の通知として保持し、compiler/runtime warningとは分けた。

## 未完了条件

実Apple署名・profile/App Group更新、実APNs、Widget/ControlのOS経由実行、Live Activityの実表示、WatchConnectivity実配送、実機の音声・Bluetooth・電力は未受入。Macの管理WebRTCにはprivacy manifestの誤配置があり、別のpackage/artifact工程が必要。iPhone由来のMac表示をMac自身の通話状態表示と同一視しない。通常の音声E2EとApp Intents IPCに残るMac環境依存の停止も、このApp試験の成功で代用しない。
