Siri phraseは[WWDC23のApp Shortcuts](https://developer.apple.com/videos/play/wwdc2023/10102/)と[必須parameterの契約](https://developer.apple.com/documentation/appintents/adding-parameters-to-an-app-intent)を確認した。値を設定済みのShortcutsではそのBoolを使い、未指定時の値の質問はOSが行う契約である。実際のSiri発話認識・質問、ShortcutsへのOS登録と起動、端末解除、実機の音声は未受入。mute解除の応答は設定変更の成功を表し、マイク権限や実音声の成立を保証しない。

build logのSDK metadata processorがAppIntents依存のない既存targetに出す抽出省略メッセージは証跡へ保持し、警告を消すためのpackage変更やmetadata抽出無効化はしていない。
